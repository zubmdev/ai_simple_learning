# Vibe Coding Course 🌊🤖 (RU/EN)

Добро пожаловать на курс по **Vibe Coding**!
Welcome to the **Vibe Coding Course**!

**Vibe Coding** — это современный подход к разработке, где вы пишете код на естественном языке, выступая в роли режиссера ИИ, а не набирая синтаксис вручную.
*(A modern approach to software development: you write code with natural language, directing AI agents instead of typing syntax manually.)*

## 🎯 О курсе / About the Course

- **Длительность:** 8 недель / 8 weeks.
- **Время:** ~3.5 ч/неделя (Beginner), ~1.5 ч/неделя (Programmer).
- **Стоимость:** весь контент **100% бесплатно**. Платное — только индивидуальные консультации (см. ниже).
- **Языки:** RU — полный курс; EN — вступление и словарь (перевод — позже).

## 🖥 Железо / Hardware (курс адаптивен)

- **Tier 1 — только CPU:** быстрые ответы через бесплатные AI-API (Groq, Gemini AI Studio, OpenRouter).
- **Tier 2 — 4GB GPU:** локальные модели через Ollama.
- **Tier 3 — 16GB+ GPU:** продвинутые локальные модели через Ollama.

## 📚 Программа / Curriculum (8 недель)

1. **Неделя 1:** настройка и первый агентский цикл.
2. **Неделя 2:** промпты как спецификации.
3. **Неделя 3:** контекст-инжиниринг.
4. **Неделя 4:** агентский harness — rules, skills, память.
5. **Неделя 5:** MCP — протокол, инструменты и безопасность.
6. **Неделя 6:** реальный проект (+.Creator-модуль для контента).
7. **Неделя 7:** отладка и рефакторинг с ИИ.
8. **Неделя 8:** финальный проект и open source.

> ℹ️ Материалы обновляются до агентского стека 2026. Актуальные модели и инструменты смотрите Week 1 и Telegram-канал. Словарь терминов — [Glossary (RU)](./ru/beginner/Glossary.md).

## 💬 Платные консультации / Paid consultations

Единственная платная услуга курса:

- **Что:** 60-минутный разбор *вашего* проекта, конфига или застрявшей задачи (консультация, не обучение).
- **Цена:** 60 BYN за сессию (вступительная цена; после первых 10 сессий — 90 BYN).
- **Формат:** разовая запись на конкретный слот; оплата переводом, чек предоставляется.
