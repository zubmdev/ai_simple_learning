# День 1: Что такое Vibe Coding? Смена мышления 🧠

Добро пожаловать в новую эру разработки! Забудьте всё, что вы знали о "правильном" программировании. Мы здесь не для того, чтобы зубрить синтаксис. Мы здесь, чтобы стать режиссёрами цифровых миров.

---

## Ты — режиссёр, не тайпер

Традиционное программирование учит: "учи синтаксис, пиши код руками, страдай над точкой с запятой". Vibe Coding говорит: **"Опиши идею на русском языке, ИИ напишет код за тебя"**.

### Аналогия для понимания

🎯 **Представь:**

| Раньше | Теперь |
|--------|--------|
| Ты — машинистка | Ты — кинорежиссёр |
| Печатаешь каждый символ | Даёшь инструкции оператору |
| Знаешь каждую кнопку камеры | Знаешь только desired result |
| 8 часов на 100 строк кода | 8 минут на 100 строк кода |

**Как это работает:**

```text
Традиционный подход:
1. Выучить Python (3-6 месяцев)
2. Выучить синтаксис, типы данных, циклы
3. Написать код вручную
4. Исправить ошибки
5. Готово через 8 часов

Vibe Coding подход:
1. Написать на русском: "Создай калькулятор"
2. ИИ генерирует код за 30 секунд
3. Проверить результат
4. Готово через 5 минут
```

---

## Почему это работает сейчас?

### 1️⃣ LLM модели стали умнее

Большие языковые модели (Large Language Models) достигли уровня, когда они понимают:
- Контекст и нюансы
- Языки программирования
- Best practices и паттерны

**Примеры моделей:**
- **GPT-OSS, Qwen, Gemma** — открытые модели, можно запустить дома через Ollama
- **Groq API** — бесплатный доступ к мощным открытым моделям
- **Qwen3 Coder** — модель, специализированная для кода

### 2️⃣ Open Source инструменты доступны

Больше не нужно платить $20/мес за ИИ-ассистента:
- **Cline** — полностью бесплатный ИИ-агент для VS Code
- **Ollama** — запуск моделей на твоём компьютере
- **Groq API** — бесплатный доступ к мощным моделям

### 3️⃣ Время — новый ресурс

Зачем тратить часы на написание кода, если можно потратить минуты на описание?

**Сравнение времени:**

| Задача | Традиционно | Vibe Coding |
|--------|-------------|-------------|
| Скрипт для обработки CSV | 2 часа | 10 минут |
| Простой REST API | 4 часа | 20 минут |
| Парсер сайта | 6 часов | 30 минут |
| Telegram бот | 8 часов | 1 час |

## Главный принцип Vibe Coding

> **Твоя задача — быть понятным, а не знать синтаксис.**

### Пример мышления

❌ **Старое мышление:**
> "Я не знаю Python, поэтому не могу написать скрипт. Мне нужно сначала выучить язык."

✅ **Vibe Coding мышление:**
> "Я опишу задачу на русском, а ИИ напишет на Python. Потом я проверю результат."

---

## Цикл агента — главный навык курса

Vibe Coding — это не «попросил и скопировал». Это управляемый цикл из шести шагов:

1. **Результат** — сформулируй, что должно получиться в итоге
2. **Контекст** — дай агенту нужные файлы, данные и вводные
3. **Делегирование** — опиши задачу и передай её агенту
4. **Ревью** — посмотри diff: какие изменения агент предлагает
5. **Проверка** — запусти и убедись, что работает
6. **Восстановление** — если агент ошибся, отклони правку или попроси исправить

Ключевая мысль: **агент предлагает изменения, а решение принимаешь ты**. Никогда не доверяй код, который не проверил.

В День 4 ты пройдёшь этот цикл целиком на реальной программе. Сегодня — просто запомни шаги.

---

## Что такое "Vibe" в Vibe Coding?

**Vibe** (вайб) — это настроение, ощущение, стиль.

В программировании это означает:
- Ты фокусируешься на **что** сделать, а не **как**
- Ты описываешь результат, а не процесс
- Ты доверяешь ИИ техническую часть
- Ты контролируешь качество и логику

### Цитата для вдохновения

> *"Vibe Coding is about expressing your intent clearly and letting the AI handle the implementation details. You become the architect, not the bricklayer."*

## Мифы о Vibe Coding

### Миф 1: "ИИ заменит программистов"

**Реальность:** ИИ не заменит программистов, но программисты, использующие ИИ, заменят тех, кто не использует.

### Миф 2: "Мне всё равно нужно учить синтаксис"

**Реальность:** Ты будешь узнавать синтаксис постепенно, в процессе работы. Как ребёнок учит язык — не по учебникам, а из общения.

### Миф 3: "Это только для простых задач"

**Реальность:** С правильным промптингом ИИ может создавать сложные системы. В этом курсе ты построишь реальный проект.

## 🎯 Миссия дня

**Артефакт:** заметка с тремя задачами для ИИ-агента, каждая по шаблону ниже.

Возьми листок бумаги или открой заметки. Запиши 3 задачи, которые ты хотел бы делегировать агенту:

1. **Личная задача** (например: "Напоминать о днях рождения")
2. **Рабочая задача** (например: "Сортировать файлы по папкам")
3. **Учебная задача** (например: "Создать викторину по истории")

Формат записи:

```text
Задача 1: [описание]
Что должно делать: [детали]
Почему это важно: [мотивация]
```

### Пример:

```text
Задача 1: Трекер привычек
Что должно делать: Приложение, где я отмечаю выполнил ли я привычку сегодня
Почему это важно: Хочу выработать привычку читать 30 минут в день

Задача 2: Сортировка загрузок
Что должно делать: Скрипт, который раскладывает файлы из Downloads по папкам (картинки, документы, видео)
Почему это важно: В папке Downloads хаос, тратлю 10 минут в день на поиск файлов

Задача 3: Генератор идей для обедов
Что должно делать: Предлагает что приготовить на обед из имеющихся продуктов
Почему это важно: Каждый день думаю что приготовить, это забирает энергию
```

### Проверка миссии

- [ ] В заметке ровно 3 задачи
- [ ] У каждой задачи есть «Что должно делать» — измеримый результат
- [ ] У каждой задачи есть «Почему это важно» — твоя мотивация

Эти задачи пригодятся на практике: в Дне 4 и Дне 5 ты делегируешь агенту похожие формулировки.
