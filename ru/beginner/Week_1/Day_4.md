## Часть 1: Подготовка рабочего пространства

### Шаг 1: Создай папку для проекта

**Windows:**

1. Открой **File Explorer** (`Win + E`)
2. Перейди в удобное место (например, `Documents` или `D:\`)
3. Правый клик → **New** → **Folder**
4. Назови папку: `vibe-coding`
5. Открой папку

**macOS:**

1. Открой **Finder**
2. Перейди в `Documents`
3. Нажми `Cmd + Shift + N` (новая папка)
4. Назови папку: `vibe-coding`
5. Открой папку

**Linux:**

```bash
# Открой Terminal
mkdir -p ~/Documents/vibe-coding
cd ~/Documents/vibe-coding
```

### Шаг 2: Открой папку в VS Code

**Способ 1 (рекомендуется):**

1. Открой VS Code
2. Нажми `Ctrl + K`, затем `Ctrl + O` (или `Cmd + K`, `Cmd + O` на Mac)
3. Выбери созданную папку `vibe-coding`
4. Нажми **"Select Folder"**

**Способ 2:**
- Windows: Правый клик на папке → **"Open with Code"**
- macOS: Перетащи папку на иконку VS Code в Dock
- Linux: В терминале: `code ~/Documents/vibe-coding`

**Способ 3:**
1. В VS Code: **File** → **Open Folder...**
2. Выбери папку `vibe-coding`

## Часть 2: Твой первый промпт

### Открой панель Cline

Кликни на иконку Cline слева в Activity Bar

### Напиши промпт

В поле ввода напиши:

```
Привет! Я новичок в программировании. 
Напиши игру "Угадай число" на Python.

Требования:
1. Компьютер загадывает случайное число от 1 до 100
2. Пользователь вводит число
3. Компьютер говорит: "больше", "меньше" или "угадал!"
4. В конце показывает количество попыток
5. Добавь понятные комментарии к каждой строке
6. Используй простые конструкции, без функций

Код должен быть понятен для новичка.
```

Нажми Enter или кнопку отправки.

### Что произойдёт

ИИ начнёт генерировать код. Ты увидишь:

```python
import random  # Импортируем модуль для случайных чисел

# Загадываем число от 1 до 100
secret_number = random.randint(1, 100)

# Счётчик попыток
attempts = 0

print("Добро пожаловать в игру 'Угадай число'!")
print("Я загадал число от 1 до 100. Попробуй угадать!")

# Основной цикл игры
while True:
    # Получаем число от пользователя
    guess = int(input("Введите число: "))
    
    # Увеличиваем счётчик попыток
    attempts += 1
    
    # Проверяем, угадал ли пользователь
    if guess == secret_number:
        print(f"Поздравляю! Вы угадали число за {attempts} попыток!")
        break
    elif guess < secret_number:
        print("Моё число больше!")
    else:
        print("Моё число меньше!")
```

## Часть 6: Улучшение через промпты

### Проблема: Пользователь может ввести не число

Попробуй ввести букву вместо числа. Программа упадёт с ошибкой!

### Попроси ИИ исправить

В том же чате Cline напиши:

```
Отлично! Но есть проблема: если пользователь введёт не число, 
программа падает с ошибкой.

Исправь код так, чтобы:
1. Программа не падала при вводе букв
2. Выводила сообщение "Введите число, а не текст!"
3. Попроси ввести число заново
4. Добавь возможность выйти из игры, введя "exit"
5. Перепиши весь код целиком с этими улучшениями
```

ИИ даст улучшенный код:

```python
import random

secret_number = random.randint(1, 100)
attempts = 0

print("Добро пожаловать в игру 'Угадай число'!")
print("Я загадал число от 1 до 100. Попробуй угадать!")
print("Введите 'exit' для выхода из игры.")

while True:
    user_input = input("Введите число: ")
    
    # Проверка выхода
    if user_input.lower() == 'exit':
        print(f"До свидания! Загаданное число было {secret_number}.")
        break
    
    # Проверка, что введено число
    try:
        guess = int(user_input)
    except ValueError:
        print("Введите число, а не текст!")
        continue
    
    attempts += 1
    
    if guess == secret_number:
        print(f"Поздравляю! Вы угадали число за {attempts} попыток!")
        break
    elif guess < secret_number:
        print("Моё число больше!")
    else:
        print("Моё число меньше!")
```

### Обнови файл

1. Скопируй новый код
2. Выдели весь старый код в файле (`Ctrl + A`)
3. Вставь новый код (`Ctrl + V`)
4. Сохрани (`Ctrl + S`)

- ✅ Не падает при вводе букв

## Часть 7: Попроси объяснение

### Ты не обязан понимать код!

Но можешь попросить ИИ объяснить:

```
Объясни мне этот код простыми словами, 
как для человека, который никогда не программировал.
Разбей объяснение по строкам.
```

ИИ объяснит:

```
Строка 1: import random
→ Подключаем "библиотеку" random, которая умеет генерировать случайные числа.
  Представь, что это коробка с инструментами для случайных чисел.

Строка 3: secret_number = random.randint(1, 100)
→ Создаём переменную secret_number и кладём туда случайное число от 1 до 100.
  random.randint(1, 100) — это команда "дай мне случайное число от 1 до 100".

Строка 4: attempts = 0
→ Создаём счётчик попыток, начинаем с 0.
  Это как табло, которое показывает, сколько раз ты попробовал угадать.

... (и так далее)
```
