# День 4: Первый диалог с кодом 💬

Сегодня ты напишешь свою первую программу, управляя агентом Cline. Без зубрёжки синтаксиса. Без учебников. Только ты, задача и проверенный результат.

---

## 🎯 Цель дня

Пройти первый полный цикл агента и получить рабочую игру "Угадай число" на Python, не зная языка программирования.

**Цикл агента, который ты сегодня освоишь:**

```text
1. Результат      — сформулируй, что должно получиться
2. Контекст       — скажи агенту, где он работает и с чем
3. Делегирование  — опиши задачу и передай Cline
4. Ревью diff     — посмотри, какие изменения предлагает агент
5. Проверка       — запусти и убедись, что работает
6. Восстановление — если агент ошибся, отклони или попроси исправить
```

**Ты научишься:**
- Формулировать результат задачи, а не процесс
- Делегировать задачу агенту с нужным контекстом
- Читать diff и одобрять/отклонять изменения
- Проверять результат запуском
- Восстанавливаться после неудачной правки

- **Что агент должен знать?** (контекст) — он в пустой папке `vibe-coding`, это будет один файл `guess_number.py` на Python, пользователь — новичок

### Шаг 3: Делегируй задачу

Вставь в поле ввода Cline:

```text
Я новичок в программировании. Это пустая папка проекта vibe-coding.

Создай файл guess_number.py — игру "Угадай число" на Python.

Результат (что должно работать):
1. Компьютер загадывает случайное число от 1 до 100
2. Пользователь вводит число
3. Компьютер говорит: "больше", "меньше" или "угадал!"
4. В конце показывает количество попыток
5. Понятные комментарии к каждой строке — я учусь по ним
6. Простые конструкции, без функций

```

### Что произойдёт

ИИ начнёт генерировать код. Ты увидишь:

```python
import random  # Импортируем модуль для случайных чисел

# Загадываем число от 1 до 100
secret_number = random.randint(1, 100)

# Счётчик попыток
attempts = 0

print("Добро пожаловать в игру 'Угадай число'!")
print("Я загадал число от 1 до 100. Попробуй угадать!")

# Основной цикл игры
while True:
    # Получаем число от пользователя
    guess = int(input("Введите число: "))
    
    # Увеличиваем счётчик попыток
    attempts += 1
    
    # Проверяем, угадал ли пользователь
    if guess == secret_number:
        print(f"Поздравляю! Вы угадали число за {attempts} попыток!")
        break
    elif guess < secret_number:
        print("Моё число больше!")
    else:
        print("Моё число меньше!")
```

## Часть 3: Цикл агента, шаг 4 — ревью diff и одобрение

### Что произойдёт после отправки

Cline не станет молча менять файлы. Сначала он покажет **план**, затем предложит **конкретное изменение**: создать файл `guess_number.py`. Ты увидишь окно с **diff** — сравнением «было / стало»:

- 🟩 **Зелёные строки** — то, что агент добавляет
- 🟥 **Красные строки** — то, что агент удаляет
- Кнопки **Approve** (принять) и **Reject** (отклонить) — решение всегда за тобой

У тебя нет файлов, поэтому diff покажет создание нового файла целиком. Просмотри его: примерно такой код появится в проекте.

```python
import random  # Импортируем модуль для случайных чисел

# Загадываем число от 1 до 100
secret_number = random.randint(1, 100)

# Счётчик попыток
attempts = 0

print("Добро пожаловать в игру 'Угадай число'!")
print("Я загадал число от 1 до 100. Попробуй угадать!")

# Основной цикл игры
while True:
    # Получаем число от пользователя
    guess = int(input("Введите число: "))
    
    # Увеличиваем счётчик попыток
    attempts += 1
    
    # Проверяем, угадал ли пользователь
    if guess == secret_number:
        print(f"Поздравляю! Вы угадали число за {attempts} попыток!")
        break
    elif guess < secret_number:
        print("Моё число больше!")
    else:
        print("Моё число меньше!")
```

Сверь diff с задачей: все 6 пунктов результата выполнены? Комментарии есть? Если да — жми **Approve**. Файл появится в папке `vibe-coding`, и ты увидишь его в панели Explorer слева.

> 💡 **Привычка на всю жизнь:** Approve — это не формальность. Читай, что подписываешь. Agent предлагает, ты решаешь.

**Важно:** расширение `.py` означает, что это файл Python. Если VS Code предложит установить поддержку Python — соглашайся.

## Часть 5: Второй проход цикла — улучшение с ревью diff

### Делегируй исправление

В том же чате Cline напиши:

```text
Отлично! Но есть проблема: если пользователь введёт не число,
программа падает с ошибкой.

Исправь код так, чтобы:
1. Программа не падала при вводе букв
2. Выводила сообщение "Введите число, а не текст!"
3. Просила ввести число заново
4. Добавь возможность выйти из игры, введя "exit"
```

### Снова ревью diff

Cline предложит изменить `guess_number.py`. Теперь diff будет интереснее: красные строки — старый код, зелёные — новый. Найди в diff те места, где добавилась проверка ввода, и убедись, что правки соответствуют всем 4 пунктам задачи. Потом жми **Approve**.

Ожидаемые изменения в коде:

```python
import random

secret_number = random.randint(1, 100)
attempts = 0

print("Добро пожаловать в игру 'Угадай число'!")
print("Я загадал число от 1 до 100. Попробуй угадать!")
print("Введите 'exit' для выхода из игры.")

while True:
    user_input = input("Введите число: ")
    
    # Проверка выхода
    if user_input.lower() == 'exit':
        print(f"До свидания! Загаданное число было {secret_number}.")
        break
    
    # Проверка, что введено число
    try:
        guess = int(user_input)
    except ValueError:
        print("Введите число, а не текст!")
        continue
    
    attempts += 1
    
    if guess == secret_number:
        print(f"Поздравляю! Вы угадали число за {attempts} попыток!")
        break
    elif guess < secret_number:
        print("Моё число больше!")
    else:
        print("Моё число меньше!")
```

### Повторная проверка

Одобрил diff — проверяй заново. Запусти:

```bash
python guess_number.py
```

И прогони три сценария:

1. Введи букву → должно появиться «Введите число, а не текст!», программа не падает
2. Введи `exit` → игра прощается и называет загаданное число
3. Сыграй до победы → счётчик попыток работает

**✅ Все три сценария прошли — улучшение подтверждено.**

## Часть 6: Цикл агента, шаг 6 — восстановление

Агент ошибается, и это нормально. Главное — уметь откатиться:

**Вариант 1: Отклони до применения.** Дифф не соответствует задаче? Жми **Reject** и уточни задачу: что именно не так.


**Вариант 3: Скат.** Если разговор зашёл в тупик — удали `guess_number.py` в Explorer (правый клик → Delete) и делегируй создание файла заново, с тем же первым промптом. Потеря — минута, не час.

## Практические советы

### 💡 Совет 1: Разбивай задачи на части

Не делегируй всё сразу. Лучше:

1. Сначала: "Напиши базовую версию"
2. Потом: "Добавь обработку ошибок"
3. Потом: "Добавь уровни сложности"

Маленькие задачи → маленькие diff → легче проверять.

### 💡 Совет 2: Всегда проверяй запуск

Агент может ошибаться! После каждого Approve:
- Запускай код
- Тестируй разные сценарии
- Нарочно вводи некорректные данные

### 💡 Совет 3: Не отправляй секреты

Пароли, ключи и файлы вроде `.env` не должны попадать в чат агента — особенно если модель работает через облачный API (Groq, Gemini). Секреты — не контекст.

### 💡 Совет 4: Проси комментарии

Всегда добавляй в задачу:

```text
Добавь комментарии к каждой строке.
```

Это поможет тебе учиться.

### 💡 Совет 5: Используй "Объясни"

Если что-то не понятно:

```text
Объясни эту строку: [вставь строку кода]
Почему используется именно этот код?
```
