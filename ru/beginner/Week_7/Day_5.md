## Часть 4: Поломка №3 — "Ошибочная валидация"

### Сломай:

```
Открой app.js и ИЗМЕНИ условие валидации:

БЫЛО:
if (text) {
    addTask(text);
    taskInput.value = '';
}

СТАЛО:
if (text.length > 100) {  // Неправильное условие!
    addTask(text);
    taskInput.value = '';
}
```

### Проверь:

```
1. Обнови страницу
2. Введи короткую задачу: "Купить молоко"
3. Нажми "Добавить"
4. Что случилось? (Ничего не добавилось!)
5. Введи длинную задачу (больше 100 символов)
6. Нажми "Добавить"
7. Добавилось! Но это неправильно!
```

### Опиши проблему ИИ:

```
Проблема: Не могу добавить короткие задачи.

Шаги:
1. Ввожу "Купить молоко"
2. Нажимаю "Добавить"
3. Ничего не происходит

Но если введу очень длинный текст (100+ символов) - добавляется.

Ожидание: Любая задача должна добавляться

Код app.js:
[вставь текущий код]

Что не так?
```

### Почини с помощью ИИ:

```
Промпт:
"Исправь валидацию.
Задача должна добавляться, если текст не пустой.
Минимальная длина: 1 символ.
Максимальная длина: 200 символов (если больше - показать ошибку)."
```

### Проверь:

```
1. Обнови страницу
2. Введи "Купить молоко"
3. Нажми "Добавить"
4. Добавилось? ✅
5. Введи пустую строку
6. Нажми "Добавить"
7. Не добавилось? ✅

Починено!
```

## Часть 5: Напиши тест

### Промпт для ИИ:

```
@Files: app.js

Напиши тесты для всех функций:
1. addTask - добавление задачи
2. toggleTask - отметка выполненной
3. deleteTask - удаление задачи
4. saveTasks - сохранение в localStorage
5. loadTasks - загрузка из localStorage

Проверь:
- Основные сценарии (работает)
- Краевые случаи (пустой ввод, длинный ввод)
- Взаимодействие с localStorage

Используй Jest.
Объясни каждый тест.
```

### Создай файл теста:

```bash
# Создай файл
touch app.test.js
```

### Вставь код от ИИ:

```javascript
// app.test.js
// Код, который сгенерировал ИИ
```

### Запусти тесты:

```bash
npm test
```

### Ожидаемый результат:

```
PASS  ./app.test.js
  addTask
    ✓ должна добавлять задачу
    ✓ не должна добавлять пустую задачу
    ✓ не должна добавлять задачу > 200 символов
  toggleTask
    ✓ должна переключать статус задачи
  deleteTask
    ✓ должна удалять задачу
    ✓ не должна падать при удалении несуществующей задачи
  saveTasks
    ✓ должна сохранять в localStorage
  loadTasks
    ✓ должна загружать из localStorage

Test Suites: 1 passed, 1 total
Tests:       8 passed, 8 total
```

```
