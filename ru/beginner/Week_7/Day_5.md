# День 5: Миссия — сломай, почини, откатись 💥🔧

**Трек:** 🌱 Начинающий | **Время:** 60 минут

---

## 🎯 Цель дня

Применить всю неделю на практике: три поломки, каждая чинится через дебаг-цикл, каждое изменение защищено эвалом, один осознанный откат через git.

---

## Часть 1: Подготовка — якорь вместо страха ⚓

### Шаг 1: Зафиксируй рабочее состояние

```bash
cd ~/projects/todo-app
git add .
git commit -m "Рабочее состояние перед миссией недели"
```

Это твоя точка возврата. Что бы ни случилось дальше, одна команда вернёт проект сюда.

### Шаг 2: Убедись, что проект работает

```text
1. Открой index.html в браузере
2. Добавь задачу, отметь выполненной, удали
3. Перезагрузи страницу — задачи на месте
4. Консоль (F12) чистая

❌ Не работает? Сначала почини через дебаг-цикл, потом начинай миссию.
```

```text
        Запиши симптом: «кнопки нет, добавить нельзя».

Шаг 2 — контекст:
```

```text
Симптом: не могу добавить задачу — на странице нет кнопки.

Файл: [прикрепи index.html]
```

## Часть 3: Поломка №2 — задачи не сохраняются 💾

### Сломай руками

Открой `app.js` и закомментируй вызов сохранения:

```javascript
// saveTasks();
```

### Почини через дебаг-цикл

```text
Симптом: задачи пропадают после перезагрузки страницы.
Шаги: 1) добавляю задачу 2) она в списке 3) перезагружаю — пусто
Файл: [прикрепи app.js]
Ожидание: задачи сохраняются между перезагрузками.
Найди причину и объясни её до правок.
```

Читай дифф: раскомментирована одна строка или агент «заодно» переписал половину файла? Второе — отклонить. Проверь строку 4 эвала.

## Часть 4: Поломка №3 — инвертированная валидация 🔃

### Сломай руками

В `app.js` замени условие добавления:

```javascript
// БЫЛО:
if (text) {
// СТАЛО:
if (text.length > 100) {
```

Теперь короткие задачи не добавляются, а длиннющие — добавляются.

### Почини — и отработай круг

Дай агенту контекст по шаблону. Если агент с двух попыток не попал — это сценарий недели:

```text
🚩 Две неудачные попытки подряд = стоп.

1. Откати: git restore app.js
2. Убедись: git status чистый, эвал в состоянии до попыток
3. Новый диалог, полный контекст: симптом + шаги + ошибка
4. Один фикс → дифф → проверка
```

Откат здесь — не поражение, а экономия 20 минут кругов. Проверь строки 1–3 эвала: короткие добавляются, пустые нет, слишком длинные — с ошибкой.

## 🧠 Ключевые принципы недели

| Принцип | Объяснение |
|---------|------------|
| **Воспроизведи** | Нет шагов воспроизведения — нет починки |
| **Контекст** | Полная ошибка + файлы решают больше, чем «почини» |
| **Одно изменение** | Один фикс за раз — видно, что помогло |
| **Дифф перед Approve** | Прочитал — одобрил. Не прочитал — не одобрял |
| **Откат — норма** | 2 попытки без результата → `git restore` и новый запрос |
| **Эвал после каждого** | Изменение без прогона эвала не считается готовым |
