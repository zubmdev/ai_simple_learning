## 🎯 Цели недели

К концу недели ты:
- ✅ Поймёшь агентный подход: ты ставишь задачу — агент делает, ты проверяешь
- ✅ Установишь VS Code + Cline
- ✅ Выберешь «мозг» под своё железо: бесплатный API или Ollama
- ✅ Пройдёшь первый полный цикл агента: результат → контекст → делегирование → ревью diff → проверка
- ✅ Напишешь первые программы без знания синтаксиса
