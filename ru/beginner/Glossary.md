## Основные термины

| Термин | Простыми словами | Пример |
|--------|------------------|--------|
| **LLM** (Large Language Model) | "Мозг" ИИ — программа, которая понимает текст и генерирует ответы | GPT-OSS, Qwen, Gemma |
| **Промпт** | Твоё сообщение/запрос к ИИ | "Напиши игру на Python" |
| **Код** | Инструкции для компьютера на понятном ему языке | `print("Hello")` |
| **Программа** | Набор инструкций (кода), которые выполняет компьютер | Игра, сайт, приложение |
| **Скрипт** | Небольшая программа, обычно автоматизирующая что-то | Скрипт для сортировки файлов |

## ИИ и модели

| Термин | Простыми словами | Пример |
|--------|------------------|--------|
| **Модель** | Конкретная версия ИИ с определёнными возможностями | qwen3.5:2b, gpt-oss:20b |
| **API** (Application Programming Interface) | Способ, которым программы общаются друг с другом | Groq API, OpenAI API |
| **API-ключ** | Пароль для доступа к API | `gsk_abc123...` |
| **Токен** | Единица текста для ИИ (≈ 1 слово или его часть) | "Hello" = ~1-2 токена |
| **Инференс** | Процесс генерации ответа ИИ | ИИ "думает" и отвечает |
| **Окно контекста** | Сколько текста ИИ может "помнить" за один раз | 4K, 128K, 1M токенов |

## Железо и локальный ИИ

| Термин | Простыми словами | Пример |
|--------|------------------|--------|
| **GPU** (Graphics Processing Unit) | Видеокарта — нужна для быстрой работы ИИ локально | NVIDIA RTX 3060 |
| **VRAM** (Video RAM) | Память видеокарты — чем больше, тем мощнее модель можно запустить | 8GB, 16GB VRAM |
| **CPU** (Central Processing Unit) | Процессор — основной "мозг" компьютера | Intel i7, AMD Ryzen 5 |
| **RAM** (Оперативная память) | Временная память компьютера | 16GB, 32GB RAM |
| **Ollama** | Программа для запуска ИИ на твоём компьютере | `ollama run qwen3.5:2b` |
| **CUDA** | Технология NVIDIA для ускорения ИИ | — |

## ИИ-агенты и инструменты

| Термин | Простыми словами | Пример |
|--------|------------------|--------|
| **Расширение** | Плагин для VS Code, добавляющий функционал | Cline, Python |
| **Рабочая область** | Папка с проектом, открытая в VS Code | — |
| **Терминал (в VS Code)** | Встроенный терминал в VS Code | `Ctrl + `` ` |
| **Cline** | ИИ-агент для VS Code: читает файлы, правит код и запускает команды по твоей задаче | Опиши задачу в панели Cline |
| **OpenCode** | ИИ-агент в терминале (CLI) — следующий шаг для программистов | `opencode` в папке проекта |
| **`AGENTS.md`** | Файл с правилами проекта для ИИ-агента: что можно, что нельзя, как проверять результат | `AGENTS.md` в корне проекта |

## Агентный цикл и обвязка

| Термин | Простыми словами | Пример |
|--------|------------------|--------|
| **Агентный цикл** | Как работает ИИ-агент: результат → контекст → делегирование → проверка → восстановление | Описал задачу → агент правит код → ты проверяешь diff |
| **Контекст-инжиниринг** | Умение выбрать, что показать агенту: нужные файлы, логи, правила — в рамках бюджета контекста | Дать 2 нужных файла вместо всего проекта |
| **Обвязка агента** | Всё, что превращает модель в агента: правила, скиллы, память, субагенты, права | Cline + `AGENTS.md` + скиллы |
| **Скилл** | Готовый плейбук для типовой задачи, который можно переиспользовать | Скилл «проверь код перед коммитом» |
| **Память агента** | Заметки агента: сессионные (живут в рамках чата) и постоянные (сохраняются между сессиями) | Файл с договорённостями по проекту |
| **Субагент** | Мини-агент, которого основной агент запускает для подзадачи, чтобы беречь главный контекст | Субагент ищет нужный код по всему проекту |
| **MCP** (Model Context Protocol) | Протокол, который подключает к агенту инструменты, ресурсы и промпты; серверы бывают локальные (stdio) и удалённые | MCP-сервер с доступом к GitHub |
| **Одобрения** | Ты подтверждаешь каждое действие агента — принцип наименьших прав | Нажать Approve перед правкой файла |
| **Diff-ревью** | Просмотр изменений до одобрения: видно, что именно агент собрался менять | Красные и зелёные строки в diff |
| **Оценка, эвал (evals)** | Чек-лист «вход → ожидаемый выход» для проверки, что агент работает верно | 5 задач — все решены правильно |
| **Три уровня доступа** | Три варианта запуска ИИ в курсе: CPU + бесплатный API; 4GB GPU; 16GB GPU | CPU + Groq `openai/gpt-oss-20b`; 4GB GPU — Ollama `qwen3.5:2b`; 16GB GPU — Ollama `gpt-oss:20b`. Проверено: 2026-10-24 |
