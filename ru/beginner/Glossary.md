## Основные термины

| Термин | Простыми словами | Пример |
|--------|------------------|--------|
| **LLM** (Large Language Model) | "Мозг" ИИ — программа, которая понимает текст и генерирует ответы | GPT-OSS, Qwen, Gemma |
| **Промпт** | Твоё сообщение/запрос к ИИ | "Напиши игру на Python" |
| **Код** | Инструкции для компьютера на понятном ему языке | `print("Hello")` |
| **Программа** | Набор инструкций (кода), которые выполняет компьютер | Игра, сайт, приложение |
| **Скрипт** | Небольшая программа, обычно автоматизирующая что-то | Скрипт для сортировки файлов |

---

## ИИ и модели

| Термин | Простыми словами | Пример |
|--------|------------------|--------|
| **Модель** | Конкретная версия ИИ с определёнными возможностями | qwen3.5:2b, gpt-oss:20b |
| **API** (Application Programming Interface) | Способ, которым программы общаются друг с другом | Groq API, OpenAI API |
| **API-ключ** | Пароль для доступа к API | `gsk_abc123...` |
| **Токен** | Единица текста для ИИ (≈ 1 слово или его часть) | "Hello" = ~1-2 токена |
| **Инференс** | Процесс генерации ответа ИИ | ИИ "думает" и отвечает |
| **Окно контекста** | Сколько текста ИИ может "помнить" за один раз | 4K, 128K, 1M токенов |

---

## Железо и локальный ИИ

| Термин | Простыми словами | Пример |
|--------|------------------|--------|
| **GPU** (Graphics Processing Unit) | Видеокарта — нужна для быстрой работы ИИ локально | NVIDIA RTX 3060 |
| **VRAM** (Video RAM) | Память видеокарты — чем больше, тем мощнее модель можно запустить | 8GB, 16GB VRAM |
| **CPU** (Central Processing Unit) | Процессор — основной "мозг" компьютера | Intel i7, AMD Ryzen 5 |
| **RAM** (Оперативная память) | Временная память компьютера | 16GB, 32GB RAM |
| **Ollama** | Программа для запуска ИИ на твоём компьютере | — |
| **CUDA** | Технология NVIDIA для ускорения ИИ | — |

## Программирование

| Термин | Простыми словами | Пример |
|--------|------------------|--------|
| **Python** | Язык программирования (самый популярный для новичков) | — |
| **Библиотека** | Готовый код, который можно использовать | `art`, `random` |
| **Зависимость** | Библиотека, которую нужно установить для работы программы | — |

| **Терминал** | Текстовый интерфейс для команд | cmd, PowerShell, bash |
| **IDE / Редактор кода** | Программа для написания кода | VS Code, PyCharm |
| **Git** | Система контроля версий (сохраняет историю изменений) | — |
| **Репозиторий** | Папка с проектом, отслеживаемая Git | Репозиторий на GitHub |
