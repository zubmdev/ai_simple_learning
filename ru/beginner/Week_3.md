## 🧠 Главная идея недели

```
❌ Плохо: "Вот весь проект из 100 файлов, что-то сделай"
✅ Хорошо: "Вот файл X (контекст), исправь функцию Y"
```

Контекст — это информация, которую ИИ "видит" при ответе. Много контекста = медленно и дорого. Мало контекста = ИИ не понимает задачу. Найди баланс!
