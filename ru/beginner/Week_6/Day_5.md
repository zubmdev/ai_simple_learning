## Часть 1: Что такое MVP?

### Определение:

```
MVP (Minimum Viable Product) = 
Минимально жизнеспособный продукт

Это версия продукта с минимальным набором функций,
которую можно использовать.
```

### Примеры:

```
MVP для To-Do:
✅ Добавлять задачи
✅ Отмечать выполненными
✅ Удалять задачи
✅ Сохранять в браузере

НЕ MVP (это v2.0):
❌ Категории
❌ Фильтры
❌ Шаринг
❌ Мобильное приложение
```

## Часть 2: Финальная проверка MVP

### Чеклист готовности:

```
Функционал:
[ ] Можно добавить задачу
[ ] Задача появляется в списке
[ ] Можно отметить выполненной
[ ] Можно удалить
[ ] Задачи сохраняются после перезагрузки

UI/UX:
[ ] Красивый дизайн
[ ] Адаптивность для мобильных
[ ] Уведомления работают
[ ] Сообщения понятны
[ ] Нет визуальных багов

Код:
[ ] Код читаемый
[ ] Комментарии есть
[ ] Нет console.error
[ ] README написан

Документация:
[ ] README.md есть
[ ] PLAN.md обновлён
[ ] CHANGELOG.md есть
```

### Промпт для финальной проверки:

```
@Files: index.html, styles.css, app.js

Проведи финальную проверку MVP:
1. Всё ли работает?
2. Есть ли баги?
3. Что можно быстро улучшить?
4. Готово ли к публикации?
```

## Часть 3: Деплой на GitHub Pages (опционально)

### Если хочешь опубликовать онлайн:

#### Шаг 1: Создай репозиторий на GitHub

```
1. Зайди на github.com
2. New repository
3. Назови: todo-app
4. Public
5. Create repository
```

#### Шаг 2: Инициализируй git

```
@Terminal

Инициализируй git в проекте todo-app:
- git init
- git add .
- git commit -m "Initial commit: MVP"
- Свяжи с удалённым репозиторием
```

ИИ предложит:

```bash
cd ~/projects/todo-app
git init
git add .
git commit -m "Initial commit: MVP"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/todo-app.git
git push -u origin main
```

#### Шаг 3: Включи GitHub Pages

```
1. GitHub → твой репозиторий
2. Settings → Pages
3. Source: Deploy from a branch
4. Branch: main, /(root)
5. Save
```

#### Шаг 4: Подожди 2-3 минуты

```
Твой сайт будет доступен по адресу:
https://YOUR_USERNAME.github.io/todo-app/
```
