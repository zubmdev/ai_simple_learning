## Часть 1: Что такое Scaffolding?

### Определение:

**Scaffolding (скаффолдинг)** — это создание "скелета" проекта:

```
📦 Создаём:
- Папки проекта
- Пустые файлы
- Базовую структуру файлов
- README с описанием

❌ НЕ создаём:
- Полный код
- Стили
- Логику
```

### Аналогия:

```
Scaffolding = Закладка фундамента дома

Не строишь сразу дом,
а создаёшь:
- Разметку
- Фундамент
- Каркас стен

Потом будешь заполнять деталями.
```

## Часть 2: Создание структуры через промпты

### Шаг 1: Создание папки проекта

Открой терминал в Continue.dev (или используй Bash):

```
Создай папку todo-app в моей папке проектов
```

ИИ предложит команду:

```bash
mkdir ~/projects/todo-app
```

### Шаг 2: Создание файлов

```
Создай в папке todo-app файлы:
- index.html
- styles.css
- app.js
- README.md
```

ИИ предложит:

```bash
cd ~/projects/todo-app
touch index.html styles.css app.js README.md
```

### Альтернатива: Один промпт для всего

```
Создай структуру проекта todo-app:
1. Папка todo-app
2. Внутри файлы: index.html, styles.css, app.js, README.md
3. Напиши команды для терминала
```

## Часть 3: Наполнение базовым содержимым

### HTML — Каркас страницы

```
Напиши базовую структуру HTML для index.html:
- Заголовок "To-Do App"
- Подключение styles.css
- Подключение app.js
- Комментарии, что где будет

Пока БЕЗ содержимого, только каркас.
```

Пример результата:

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>To-Do App</title>
    <!-- Подключаем стили -->
    <link rel="stylesheet" href="styles.css">
</head>
<body>
    <!-- Здесь будет контент -->
    
    <!-- Подключаем скрипт -->
    <script src="app.js"></script>
</body>
</html>
```

### README — Документация

```
Напиши README.md для проекта:
- Название проекта
- Описание
- Структура файлов
- Как запустить

```

Пример результата:

```markdown

Простое веб-приложение для управления задачами.

Позволяет:
- Добавлять задачи
- Отмечать выполненные
- Удалять задачи
- Сохранять в браузере

```
todo-app/
├── index.html    # Главная страница
├── styles.css    # Стили
├── app.js        # Логика
└── README.md     # Документация

```
2. Начни добавлять задачи!

- HTML5
- CSS3
- JavaScript (ES6+)
```

## Часть 6: Сохранение плана разработки

### Создай файл PLAN.md:

```
Создай файл PLAN.md с планом разработки:
- Цель проекта
- Функции
- Файлы
- Шаги разработки
- Текущий прогресс
```

Пример PLAN.md:

```markdown
# План разработки To-Do App

## Цель
Создать простое веб-приложение для управления задачами.

## Функции
- [x] Добавить задачу
- [x] Отметить выполненной
- [x] Удалить задачу
- [x] Сохранение в localStorage

## Файлы
- [x] index.html - создан (каркас)
- [x] styles.css - создан (база)
- [x] app.js - создан (структура)
- [x] README.md - создан

## Шаги разработки
- [x] 1. Планирование
- [x] 2. Scaffolding (сейчас)
- [ ] 3. HTML - добавить контент
- [ ] 4. CSS - добавить стили
```

## 🧠 Ключевые принципы

| Принцип | Объяснение |
|---------|------------|
| **Scaffolding сначала** | Не пиши код без структуры |
| **Комментарии важны** | Оставляй TODO для будущих шагов |
| **README обязателен** | Документируй проект сразу |
| **Проверяй структуру** | Убедись, что всё связано правильно |
| **Сохраняй план**** | PLAN.md помогает не потеряться |
