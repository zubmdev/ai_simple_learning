## Часть 2: Начало диалога с ИИ

### Первый промпт — Описание идеи:

```
Я хочу создать To-Do веб-приложение. 
Мой уровень: начинающий (никогда не программировал).
Я использую Vibe Coding (пишу код через промпты, не вручную).

Помоги мне спланировать:
1. Какие функции должны быть?
2. Какие файлы понадобятся?
3. Какие технологии использовать?
4. С чего начать разработку?
```

### Пример ответа ИИ:

```
Отлично! Давай спланируем To-Do приложение.

📁 Структура проекта:
todo-app/
├── index.html      # Главная страница
├── styles.css      # Стили (как выглядит)
├── app.js          # Логика (как работает)
└── README.md       # Документация

✨ Основные функции:
1. Добавить задачу
2. Отметить как выполненную
3. Удалить задачу
4. Сохранить в браузере (localStorage)

🛠️ Технологии:
- HTML (структура)
- CSS (внешний вид)
- JavaScript (логика)
- localStorage (хранение данных)

🚀 С чего начать:
1. Создать HTML файл с формой
2. Добавить CSS для красивого вида
3. Написать JavaScript для работы
4. Протестировать и улучшить

Готов начать? Скажи "Создай файл index.html"
```

## Часть 4: Выбор уровня сложности

### Для новичка рекомендуем: Простой уровень

```
Выбираю простой уровень.

Создай подробный план:
1. Что будет в каждом файле?
2. Как данные будут храниться?
3. Как файлы связаны между собой?
```

### Пример ответа ИИ:

```
📋 Детальный план (Простой уровень):

📄 index.html:
- Заголовок "Мои задачи"
- Форма для добавления задачи (текст + кнопка)
- Список задач (контейнер для задач)
- Каждая задача: текст + чекбокс + кнопка удаления

📄 styles.css:
- Стили для формы
- Стили для списка задач
- Стили для выполненных задач (зачёркнутый текст)
- Адаптивность для мобильных

📄 app.js:
- Функция addTask() - добавить задачу
- Функция toggleTask() - отметить выполненной
- Функция deleteTask() - удалить задачу
- Функция saveTasks() - сохранить в localStorage
- Функция loadTasks() - загрузить при старте

💾 Данные в localStorage:
{
  "tasks": [
    {
      "id": 1,
      "text": "Купить продукты",
      "completed": false
    }
  ]
}

🔗 Связи между файлами:
- index.html подключает styles.css и app.js
- app.js находит элементы из index.html по id
- app.js читает/пишет в localStorage
```

## Часть 5: Создание архитектурной схемы

### Попроси ИИ нарисовать схему:

```
Нарисуй схему, как работает приложение.
Объясни простыми словами.
```

### Пример ответа ИИ:

```
📊 Как работает приложение:

┌─────────────────────────────────────┐
│          Браузер пользователя        │
│                                     │
│  ┌───────────────────────────────┐ │
│  │  index.html                   │ │
│  │  (страница)                   │ │
│  │    ↓                          │ │
│  │  ┌─────────┐  ┌────────────┐  │ │
│  │  │ Форма   │  │   Список   │  │ │
│  │  │(добавить)│  │   задач    │  │ │
│  │  └─────────┘  └────────────┘  │ │
│  └───────────────────────────────┘ │
│         ↓                    ↑     │
│    styles.css              app.js  │
│    (красота)             (логика)  │
│                                 ↓  │
│                          ┌──────────┐│
│                          │localStorage││
│                          │  (память)  ││
│                          └──────────┘│
└─────────────────────────────────────┘

📖 Простыми словами:

1. Пользователь открывает index.html
2. Браузер показывает красивую страницу (styles.css)
3. Пользователь пишет задачу и жмёт "Добавить"
4. app.js ловит это действие
5. app.js создаёт новую задачу в памяти
6. app.js показывает задачу в списке
7. app.js сохраняет в localStorage
8. При следующем открытии app.js загружает задачи из localStorage
```
