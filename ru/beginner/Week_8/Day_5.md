# День 5: Выпускной — портфолио и что дальше 🎓

**Трек:** 🌱 Начинающий | **Время:** 50 минут

---

## 🎯 Цель дня

Собрать портфолио: оформить профиль и проекты так, чтобы ими можно было поделиться, — и решить, куда двигаться дальше.

---

## Часть 1: Что ты прошёл за 8 недель

```text
Неделя 1: Установка и первый агентный цикл 🛠️
✅ VS Code + Cline + Groq (или Ollama локально)
✅ Понял цикл: задача → diff → проверка

Неделя 2: Промпты как спецификации 📝
✅ Задача = критерии приёмки, а не пожелание
✅ Структурированные выходы и итерации

Неделя 3: Контекст 📚
✅ Выбор файлов, AGENTS.md, терминал и логи как контекст
✅ Контекстный бюджет вместо «скинь всё»

Неделя 4: Агентный harness ⚙️
✅ Правила, skills, память, субагенты

Неделя 5: MCP и безопасность 🔧
✅ Инструменты MCP, одобрение вызовов, минимум прав, секреты в .env

Неделя 6: Проект через агента 🚀
✅ To-Do App (или Creator-путь): план → функции → публикация

Неделя 7: Дебаг, тесты, откат 🐛
✅ Дебаг-цикл, логи как контекст, дифф-ревью,
   мини-эвал, git restore

Неделя 8: Капстоун 🎓
✅ Свой проект: идея → MVP → деплой → стоимость → портфолио
```

## Часть 2: Портфолио — что собираем

```text
1. GitHub-профиль с README
2. Финальный проект: код + README + демо-ссылка с Дня 4
3. To-Do App из недели 6 (тоже с README)
4. Вклад в Open Source — не обязательно сегодня,
   но это отличная следующая цель
```

### Шаг 1: README профиля

```text
1. github.com/new
2. Имя репозитория = ТВОЙ_ЛОГИН (точно совпадает с username!)
3. Public → Add a README → Create
```

Заполни README (попроси агента оформить по этому скелету):

```markdown
# Привет! Я [Имя] 👋

🌱 Vibe Coder — создаю программное обеспечение через
естественный язык: ставлю задачи агенту, проверяю результат.

## Что умею
- Ставить задачи агенту через критерии приёмки
- Давать контекст: AGENTS.md, файлы, логи
- Читать диффы и проверять изменения эвалом
- Чинить баги дебаг-циклом и откатываться через git

## Проекты
### 🚀 [Проект 1]
Что делает. Демо: ссылка с Дня 4 · Код: репозиторий на GitHub

### ✅ [Проект 2 — To-Do App]
Что делает. Демо: ссылка · Код: репозиторий на GitHub

## Стек
- Агент: Cline в VS Code
- Модели: Groq openai/gpt-oss-20b, локально Ollama
- Инструменты: Git, GitHub, GitHub Pages
```

### Шаг 2: README проекта

Проверь финальный проект — в README должны быть:

```text
✅ Демо-ссылка (GitHub Pages с Дня 4)
✅ Скриншот приложения
✅ Функции MVP — по PLAN.md
✅ Как запустить локально
✅ Секция «Разработка»: что проект сделан через агента
   в Cline, правила в AGENTS.md
✅ Секция «Что я узнал» — 5 пунктов
```

За образец возьми README из недели 6, День 5 — у тебя он уже есть, обнови ссылки и название.

### Шаг 3: Проверка портфолио

```text
1. Открой профиль в инкогнито — README виден
2. Перейди по демо-ссылке — приложение работает
3. Спроси друга: «Понятно ли, что я умею, за 30 секунд?»
```

## Часть 3: Куда дальше 🚀

```text
1. Практика: следующий проект. Навык растёт от количества
   доведённых до конца проектов, а не от сложности идей.

2. Open Source: маленький вклад — опечатка в документации,
   перевод README. Ищи по метке «good first issue» на GitHub.

3. Сообщество: ты уже в Telegram-канале курса — делись
   проектами и вопросами там.

4. Разбор своего проекта: если захочешь глазами опытного
   инженера посмотреть на твой проект или workflow с агентом,
   у автора курса есть разовые консультации. Курс полностью
   бесплатный — консультация необязательная опция, а не
   следующий шаг.
```
