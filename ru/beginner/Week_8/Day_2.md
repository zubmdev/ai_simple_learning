## Часть 1: День 2 — Начало разработки

### Шаг 1: Создай структуру проекта

```bash
mkdir ~/projects/[project-name]
cd ~/projects/[project-name]
touch index.html styles.css app.js README.md
```

### Шаг 2: Базовый HTML

```
Промпт:

Создай базовую структуру HTML для [project name].

Требования:
- Semantic HTML5
- Заголовок приложения
- Основные элементы интерфейса
- Подключение CSS и JS
- Комментарии к секциям

Пока без наполнения, только каркас.
```

### Шаг 3: Базовые стили

```
Промпт:

Создай базовые стили CSS:

Требования:
- Сброс стандартных стилей
- Шрифт sans-serif
- Цвета: [твои предпочтения]
- Адаптивность для мобильных
- Красивые кнопки и формы

Используй современные CSS.
```

### Шаг 4: Главная функция

```
Промпт:

Реализуй главную функцию: [описание]

Требования:
- [детали функции]
- Сохранение в localStorage
- Обработка ошибок
- Понятные сообщения

Используй современные JavaScript (ES6+).
```

## Часть 2: Управление контекстом

### Проблема:

```
При длинных диалогах ИИ может:
- Забывать предыдущие решения
- Путаться в файлах
- Предлагать противоречивые решения
```

### Решение:

```
1. Часто используй @Files
2. Перезапускай контекст каждые 10-15 промптов
3. Документируй решения в комментариях
4. Комить часто
```

### Пример перезапуска контекста:

```
НОВЫЙ КОНТЕКСТ

Проект: [название]
Текущее состояние:
@Files: index.html, styles.css, app.js

Что уже сделано:
✅ Создана структура
✅ Добавлена функция X
✅ Работает сохранение

Что нужно сделать сейчас:
- Добавить функцию Y
- Улучшить стили

Начни с этого, не учитывая прошлые диалоги.
```

## Часть 3: Управление моделями

### CPU Only (Free APIs):

```
Groq (Llama 3 70B):
- Быстрая генерация
- Хорош для планирования
- Хорош для простых задач
- Бесплатно

HuggingFace:
- Альтернатива
- Иногда медленнее
- Бесплатно
```

### 4GB GPU (Ollama):

```
Qwen 2.5 3B:
- Быстрая локально
- Хорош для простых задач
- Может путаться в сложной логике

Qwen 2.5 7B:
- Медленнее, но умнее
- Лучше для сложных задач
- Хорош для рефакторинга
```

### 16GB GPU (Ollama):

```
Llama 3 8B:
- Быстрая и умная
- Хорош для всего
- Рекомендуется

DeepSeek Coder:
- Специализирована на коде
- Отлично для сложной логики
- Немного медленнее
```

### Стратегия переключения:

```
Быстрое планирование → Groq / Qwen 1.5B
Сложная логика → Llama 3 8B / DeepSeek
Рефакторинг → Llama 3 8B
Дебаггинг → DeepSeek Coder
```

## Часть 4: День 3 — Завершение разработки

### Шаг 1: Дополнительные функции

```
Промпт для каждой функции:

Добавь функцию: [описание]

```

□ Третья функция работает
□ Сохранение работает
□ На мобильном выглядит хорошо

```

1. Открой F12 → Console
2. Скопируй ошибку
3. Опиши ИИ:

"Баг: [описание]
Ошибка в консоли: [вставь]
Код: @Files: app.js
Как исправить?"
```

## Часть 5: Типичные проблемы и решения

### Проблема 1: ИИ предлагает слишком сложное решение

```
Решение:

"Это слишком сложно для меня.
Предложи ПРОСТОЕ решение.
Минимум кода.
Только необходимое."
```

### Проблема 2: Функционал ломается

```
Решение:

1. Откатись к последней рабочей версии
2. Попроси ИИ исправить:

"После добавления [функция] сломалось [что].
Верни рабочее состояние.
Потом добавь функцию правильно."
```

### Проблема 3: Не хватает времени

```
Решение:

1. Урежь scope ещё больше
2. Оставь только 1-2 функции
3. Главное — ЗАКОНЧИТЬ

"У меня мало времени.
Оставь только самую важную функцию.
Остальное — в следующей версии."
```
