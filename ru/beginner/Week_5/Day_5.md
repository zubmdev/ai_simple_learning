## Часть 1: Выбор MCP-сервера для миссии

### Вариант A: File System MCP (рекомендуется) ⭐

**Почему:**
- Не нужен API ключ
- Простая установка
- Много практических применений
- Работает локально

**Для чего:**
- Анализ логов
- Поиск по файлам проекта
- Генерация документации
- Создание отчётов

### Вариант B: Brave Search MCP

**Почему:**
- Доступ к актуальной информации
- Поиск документации
- Исследование библиотек

**Нужно:**
- Бесплатный API ключ от Brave Search
- Регистрация на brave.com/search/api

## Часть 2: Установка File System MCP

### Шаг 1: Перейди в папку MCP-серверов

```bash
cd ~/mcp-servers/servers/src/filesystem
```

### Шаг 2: Установи зависимости

```bash
npm install
```

### Шаг 3: Собери проект

```bash
npm run build
```

### Шаг 4: Получи абсолютный путь

```bash
pwd
```

Запиши путь, например:
```
/home/username/mcp-servers/servers/src/filesystem
```

Полный путь к серверу:
```
/home/username/mcp-servers/servers/src/filesystem/build/index.js
```

---

## Часть 3: Настройка File System MCP в Continue.dev

### Шаг 1: Открой config.json

```bash
code ~/.continue/config.json
```

### Шаг 2: Добавь File System MCP

```json
{
  "models": [...],
  "mcpServers": {
    "sqlite": {
      "command": "node",
      "args": ["/путь/к/sqlite/build/index.js"]
    },
    "filesystem": {
      "command": "node",
      "args": [
        "/путь/к/filesystem/build/index.js",
        "/home/username/projects"
      ]
    }
  }
}
```

**Важно:** 
- Второй аргумент — это папка, к которой ИИ получит доступ
- Замени `/home/username/projects` на ТВОЮ папку с проектами
- ИИ сможет читать/писать файлы ТОЛЬКО в этой папке

### Шаг 3: Перезапусти VS Code

```
Cmd/Ctrl + Shift + P → "Reload Window"
```

## Часть 5: Миссия — Анализ проекта через MCP

### Задача:

Создать автоматическую документацию проекта на основе его структуры и кода.

### Шаг 1: Подготовка тестового проекта

Если у тебя нет проекта, создай тестовый:

```bash
mkdir -p ~/projects/demo-project
cd ~/projects/demo-project
```

Создай несколько файлов:

**index.js:**
```javascript
const express = require('express');
const app = express();
const port = 3000;

app.get('/', (req, res) => {
  res.send('Hello World!');
});

app.get('/api/users', (req, res) => {
  res.json({ users: ['Anna', 'Boris', 'Viktor'] });
});

app.listen(port, () => {
  console.log(`Server running on port ${port}`);
});
```

**package.json:**
```json
{
  "name": "demo-project",
  "version": "1.0.0",
  "main": "index.js",
  "dependencies": {
    "express": "^4.18.2"
  }
}
```

**README.md:**
```markdown
# Demo Project

Simple Express.js server.

## Installation

npm install

## Running

npm start
```

### Шаг 2: Запрос к ИИ

```
Проанализируй проект в папке demo-project:
1. Прочитай все файлы
2. Пойми структуру проекта
3. Создай файл DOCUMENTATION.md с:
   - Описанием проекта
   - Структурой файлов
   - API endpoints
   - Инструкциями по запуску
```

### Шаг 3: Что должен сделать ИИ

1. ✅ Прочитать все файлы через File System MCP
2. ✅ Проанализировать package.json (зависимости)
3. ✅ Найти API endpoints в index.js
4. ✅ Сгенерировать DOCUMENTATION.md
5. ✅ Создать файл в проекте

### Пример результата:

**DOCUMENTATION.md:**

```markdown

## Overview

```

## Часть 7: Ограничения и безопасность

### ⚠️ Важно понимать:

```
File System MCP даёт ИИ доступ к файлам.

Безопасность:
✅ Указывай только папку с проектами
❌ НЕ указывай корень системы /
❌ НЕ указывай папки с секретами (.ssh, .gnupg)
❌ НЕ указывай системные папки

ИИ может:
✅ Читать файлы
✅ Создавать файлы
✅ Редактировать файлы
❌ Удалять файлы (обычно отключено)
```

### Рекомендации:

```
1. Создай отдельную папку для экспериментов
2. Делай бэкапы важных проектов
3. Проверяй, что создаёт ИИ
4. Не давай доступ к приватным ключам
```

## Часть 8: Альтернатива — Brave Search MCP

### Если хочешь попробовать Web API:

#### Шаг 1: Получи API ключ

```
1. Зайди на https://brave.com/search/api/
2. Нажми "Get Started"
3. Зарегистрируйся
4. Скопируй API ключ
```

#### Шаг 2: Установи Brave Search MCP

```bash
cd ~/mcp-servers/servers/src/brave-search
npm install
npm run build
```

#### Шаг 3: Настрой config.json

```json
{
  "mcpServers": {
    "brave-search": {
      "command": "node",
      "args": ["/путь/к/brave-search/build/index.js"],
      "env": {
        "BRAVE_API_KEY": "твой-api-ключ"
      }
    }
  }
}
```

#### Шаг 4: Используй

```
Найди последнюю документацию по Express.js 5
```
