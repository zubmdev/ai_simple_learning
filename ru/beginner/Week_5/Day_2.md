# День 2: Первый MCP-сервер в Cline 🔌

**Трек:** 🌱 Начинающий | **Время:** 40 минут

---

## 🎯 Цель дня

Подключить первый MCP-сервер двумя способами — через Cline MCP Marketplace и вручную через конфиг — и прочитать свою первую карточку одобрения.

---

## 🛠️ Часть 1: Что понадобится

| Уровень | Железо | Модель в Cline |
|---------|--------|----------------|
| CPU + бесплатный API | любой компьютер | Groq `openai/gpt-oss-20b` |
| 4GB GPU (Ollama) | видеокарта от 4GB VRAM | `qwen3.5:2b` (запасная: `qwen3:4b`) |
| 16GB GPU (Ollama) | видеокарта от 16GB VRAM | `gpt-oss:20b` |

**Проверено: 2026-10-24.** Дополнительно нужен Node.js (ставился в Неделе 1): проверь командой `node --version`.

---

## 💡 Часть 2: Где в Cline живут MCP-настройки

Текстовые шаги (не зависят от версии интерфейса):

1. Открой панель Cline слева в Activity Bar.
2. Вверху панели найди иконку **MCP Servers** (стопка серверов/штекер).
3. Откроется окно MCP с двумя вкладками:
   - **Marketplace** — каталог серверов, установка в один клик;
   - **Installed** — уже подключённые серверы и их состояние.

Каждый сервер здесь можно включить/выключить и посмотреть список его инструментов.

---

## 🧩 Часть 3: Способ 1 — Marketplace (один клик)

Первым сервером возьмём **Memory** — локальный сервер памяти: он хранит заметки о твоём проекте между диалогами. Данные остаются на твоём компьютере.

1. Открой вкладку **Marketplace**.
2. В поиске набери `memory`.
3. Найди сервер Memory от официального каталога MCP и нажми **Install**.
4. Подтверди установку — Cline сам пропишет сервер в конфиг и запустит его.

В списке **Installed** сервер должен «загореться»: зелёный индикатор и число доступных инструментов (create_entities, search_nodes и другие).

💡 Конкретные пакеты и интерфейс меняются быстрее, чем сам протокол MCP. Если не находишь сервер по имени — ищи в Marketplace по слову `memory` или `knowledge graph` и проверяй, что сервер запускается локально (команда `npx`, а не URL).

---

## ⚙️ Часть 4: Способ 2 — ручная настройка (конфиг)

Marketplace удобен, но тебе нужно уметь настраивать серверы руками: так подключают всё, чего нет в каталоге.

1. В окне MCP нажми **Configure MCP Servers** — Cline открёт файл `cline_mcp_settings.json`.
2. Добавь сервер `memory` (если поставил через Marketplace, он уже там — сверь формат):

```json
{
  "mcpServers": {
    "memory": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-memory"],
      "env": {},
      "disabled": false,
      "autoApprove": []
    }
  }
}
```

### Что значат поля:

| Поле | Смысл |
|------|-------|
| `command` + `args` | Как запустить сервер локально (npx скачает и стартует его) |
| `env` | Переменные окружения — например, API-ключ сервера (пусто = не нужен) |
| `disabled` | Выключатель сервера, не удаляя настройку |
| `autoApprove` | Инструменты, которые сработают БЕЗ вопроса. **Держи `[]` — пусто.** |

3. Сохрани файл (`Ctrl+S`). Cline перечитает конфиг и перезапустит сервер автоматически.

🚨 `autoApprove: []` — это не «недоделка», а настройка по умолчанию, которая тебя защищает: каждый вызов инструмента сначала показывается тебе. Разрешать что-то без вопроса научимся только в День 5 и только для чтения.

## ✅ Часть 5: Проверка — даём агенту память

Открой чат Cline и напиши:

```text
Запомни: меня зовут Саша, я прохожу курс vibe coding, мой проект — трекер привычек. Сохрани это в своей памяти.
```

Cline покажет **карточку одобрения** — примерно такую:

```text
Cline wants to use a tool:
memory (MCP): create_entities
{
  "entities": [
    { "name": "Саша", "entityType": "learner" },
    { "name": "трекер привычек", "entityType": "project" }
  ]
}
[ Approve ]  [ Reject ]
```

### Как читать карточку — по шагам:

1. **Сервер:** `memory` — тот, что ты сам подключил.
2. **Инструмент:** `create_entities` — создать записи в памяти.
3. **Аргументы:** то, что будет сохранено. Совпадает с тем, что ты просил?

Если всё сходится — жми **Approve**. Теперь проверь память:

```text
Что ты обо мне помнишь?
```

Агент вызовет `search_nodes` (снова карточка — снова читаешь) и перечислит твои факты. Данные лежат в локальном файле на твоём диске — на машину ничего не ушло.

## 🔧 Часть 6: Troubleshooting

| Симптом | Что делать |
|---------|------------|
| Сервер серый / не запускается | Проверь `node --version`; открой лог сервера в окне MCP — там видна ошибка |
| «Cannot find module» при старте | npx не смог скачать пакет — проверь интернет, потом снова сохрани конфиг |
| Ошибка JSON при сохранении | Проверь запятые и кавычки: это строго валидный JSON |
| Агент «не видит» инструменты | Убедись, что сервер зелёный в Installed; напиши в чат «какие MCP-инструменты у тебя есть?» |
| Локальная модель путается в вызовах | Это ожидаемо для 4GB-моделей: для этой недели переключись на CPU+API или 16GB |

## 🧠 Ключевые принципы

| Принцип | Объяснение |
|---------|------------|
| **Marketplace** | Быстрый путь: каталог → Install → готово |
| **cline_mcp_settings.json** | Ручной путь: полный контроль над серверами |
| **autoApprove: []** | Пусто = каждый вызов через одобрение. Так и держи |
| **Карточка одобрения** | Сервер → инструмент → аргументы. Не читал — не одобряй |
| **Локальный сервер** | Данные не покидают твой компьютер |

1. Спроси агента: «Перечисли всё, что ты помнишь о моём проекте» — и одобри вызов после чтения карточки.
