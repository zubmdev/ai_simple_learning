## Часть 2: Топ-5 MCP-серверов для начинающих

### 1. 🗄️ SQLite MCP

**Что делает:** Позволяет ИИ читать SQLite базы данных

**Для чего нужен:**
- Анализ локальных баз данных
- Генерация SQL запросов
- Создание отчётов из данных

**Пример использования:**
```
Ты: "Прочитай базу shop.db и покажи топ-10 товаров по продажам"

ИИ (через SQLite MCP):
1. Подключается к shop.db
2. Читает структуру таблиц
3. Выполняет: SELECT * FROM products ORDER BY sales DESC LIMIT 10
4. Показывает результат в красивом формате
```

**Сложность установки:** ⭐ (простая)

---

### 2. 📁 File System MCP

**Что делает:** Даёт ИИ доступ к файлам на твоём компьютере

**Для чего нужен:**
- Чтение больших файлов без копирования
- Поиск по файлам
- Создание и редактирование файлов

**Пример использования:**
```
Ты: "Найди во всех логах ошибку 'Connection timeout' и посчитай сколько раз"

ИИ (через File System MCP):
1. Сканирует папку logs/
2. Ищет паттерн в файлах
3. Возвращает: "Найдено 47 вхождений в 12 файлах"
```

**Сложность установки:** ⭐⭐ (средняя)

---

### 3. 🌐 Brave Search MCP

**Что делает:** Позволяет ИИ искать информацию в интернете

**Для чего нужен:**
- Поиск актуальной документации
- Поиск решений ошибок
- Исследование библиотек

**Пример использования:**
```
Ты: "Найди последнюю версию React и её новые фичи"

ИИ (через Brave Search MCP):
1. Ищет "React latest version features 2024"
2. Возвращает краткую сводку с ссылками
```

**Сложность установки:** ⭐⭐ (нужен API ключ)

---

### 4. 🐙 GitHub MCP

**Что делает:** Даёт ИИ доступ к GitHub репозиториям

**Для чего нужен:**
- Чтение кода из репозиториев
- Создание issues
- Анализ проектов

**Пример использования:**
```
Ты: "Посмотри репозиторий facebook/react и найди файл с хуками"

ИИ (через GitHub MCP):
1. Подключается к репозиторию
2. Находит ReactHooks.js
3. Показывает содержимое
```

**Сложность установки:** ⭐⭐⭐ (нужен GitHub токен)

---

### 5. 🗺️ Google Maps MCP

**Что делает:** Работает с геолокацией и картами

**Для чего нужен:**
- Поиск мест
- Расчёт маршрутов
- Геокодирование адресов

**Пример использования:**
```
Ты: "Найди кофейни в радиусе 500м от ул. Пушкина 10"

ИИ (через Google Maps MCP):
1. Геокодирует адрес
2. Ищет nearby places
3. Возвращает список с рейтингами
```

**Сложность установки:** ⭐⭐⭐ (нужен Google API ключ)

## Часть 4: Практика — Создаём тестовую базу данных

### Для чего?

Чтобы протестировать SQLite MCP, нужна база данных. Создадим простую.

### Шаг 1: Установи SQLite (если нет)

```bash
# Ubuntu/Debian
sudo apt-get install sqlite3

# macOS
brew install sqlite

# Windows
# Скачай с https://www.sqlite.org/download.html
```

### Шаг 2: Создай тестовую базу

Создай файл `create_test_db.sql`:

```sql
-- Создаём таблицу пользователей
CREATE TABLE users (
    id INTEGER PRIMARY KEY,
    name TEXT NOT NULL,
    email TEXT UNIQUE,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- Создаём таблицу заказов
CREATE TABLE orders (
    id INTEGER PRIMARY KEY,
    user_id INTEGER,
    product TEXT NOT NULL,
    amount REAL,
    order_date DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id)
);

-- Добавляем тестовые данные
INSERT INTO users (name, email) VALUES
    ('Анна', 'anna@example.com'),
    ('Борис', 'boris@example.com'),
    ('Виктор', 'victor@example.com'),
    ('Галина', 'galina@example.com'),
    ('Дмитрий', 'dmitry@example.com');

INSERT INTO orders (user_id, product, amount) VALUES
    (1, 'Laptop', 999.99),
    (1, 'Mouse', 25.50),
    (2, 'Keyboard', 75.00),
    (3, 'Monitor', 299.99),
    (3, 'Webcam', 45.00),
    (4, 'Headphones', 120.00),
    (5, 'Laptop', 999.99),
    (1, 'USB Hub', 35.00),
    (2, 'Mouse Pad', 15.00),
    (3, 'Speaker', 85.00);
```

### Шаг 3: Создай базу

```bash
sqlite3 test.db < create_test_db.sql
```

### Шаг 4: Проверь

```bash
sqlite3 test.db "SELECT * FROM users LIMIT 3;"
```

Должен появиться вывод:

```
1|Анна|anna@example.com|2024-01-15 10:30:00
2|Борис|boris@example.com|2024-01-15 10:30:00
3|Виктор|victor@example.com|2024-01-15 10:30:00
```

## Часть 5: Что умеют MCP-серверы?

### Типы возможностей:

```
1. RESOURCES (Ресурсы) — ИИ "видит" данные
   SQLite MCP: видит таблицы, схемы, данные
   File System MCP: видит файлы, папки, содержимое

2. TOOLS (Инструменты) — ИИ "действует"
   SQLite MCP: выполняет SQL запросы
   File System MCP: создаёт, читает, редактирует файлы
   GitHub MCP: создаёт issues, читает репозитории

3. PROMPTS (Шаблоны) — готовые промпты
   SQLite MCP: "Проанализируй таблицу X"
   File System MCP: "Найди файлы с паттерном Y"
```

### Пример Resources от SQLite MCP:

```json
{
  "resources": [
    {
      "uri": "sqlite:///test.db/users",
      "name": "users table",
      "description": "Table with user data"
    },
    {
      "uri": "sqlite:///test.db/orders",
      "name": "orders table",
      "description": "Table with order data"
    }
  ]
}
```

ИИ автоматически видит эти ресурсы и может с ними работать.
