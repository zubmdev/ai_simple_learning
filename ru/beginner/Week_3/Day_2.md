## Часть 1: Как Continue.dev работает с контекстом

### Что "видит" ИИ?

```
Когда ты пишешь промпт, ИИ видит:

1. Твой промпт (текст)
2. Открытые файлы в VS Code (автоматически)
3. То, что ты явно добавил через @
4. Выделенный текст (если есть)
```

### Панель контекста

Открой Continue (`Ctrl+L`) и посмотри вниз:

```
┌─────────────────────────────┐
│  [Модель: Select ▼]         │
│  [Контекст: Files ▼]  ←─── Здесь!
├─────────────────────────────┤
│  Введите промпт...          │
└─────────────────────────────┘
```

Нажми на **"Контекст"** — увидишь список добавленных файлов.

## Часть 2: @Files — добавляем конкретные файлы

### Как использовать

```
Способ 1: Введи @ вручную

@Files: main.py, models.py, config.py

Исправь функцию в main.py

---

Способ 2: Кликни на иконку 📎

1. Нажми 📎 в поле ввода
2. Выбери "Files"
3. Выбери файлы из списка
4. Напиши промпт
```

### Примеры использования

#### Пример 1: Изменение функции

```
@Files: user_service.py

Добавь валидацию email в функцию create_user.
Если email невалидный, выбрось ValueError.
```

#### Пример 2: Создание новой функции

```
@Files: models.py, database.py

Создай функцию get_user_by_email в database.py,
используя модель User из models.py.
```

#### Пример 3: Рефакторинг

```
@Files: old_code.py, new_structure.py

Перепиши функцию process_data из old_code.py,
следуя стилю из new_structure.py.
```

## Часть 3: @Folder — добавляем папку целиком

### Когда использовать?

```
✅ Когда нужно понять структуру модуля
✅ Когда файлы в папке тесно связаны
✅ Когда не знаешь, какие именно файлы нужны

❌ Когда папка очень большая (50+ файлов)
❌ Когда нужны только 1-2 файла
```

### Как использовать

```
@Folder: src/api

Объясни, как работают эти API endpoints.
Какой паттерн используется?
```

### Практика: Анализ папки

**Задание:**

1. Открой любой свой проект в VS Code
2. Открой Continue (`Ctrl+L`)
3. Напиши:

```
@Folder: [выбери папку с кодом]

Объясни простыми словами:
1. Что делает этот код?
2. Какие основные функции?
3. Какие зависимости между файлами?
```

## Часть 4: @Terminal — добавляем вывод терминала

### Зачем это нужно?

```
Когда код падает с ошибкой, ты можешь:
❌ Скопировать ошибку вручную → вставить в чат
✅ Использовать @Terminal → ИИ увидит автоматически
```

### Как использовать

```
Способ 1: Введи @ вручную

@Terminal

Почему падает эта ошибка? Как исправить?

---

Способ 2: Кликни на иконку 📎

1. Нажми 📎
2. Выбери "Terminal Output"
3. Напиши промпт
```

### Пример: Дебаггинг

```
1. Запусти код: python main.py
2. Код упал с ошибкой
3. Не закрывай терминал!
4. Открой Continue
5. Напиши:

@Terminal

Объясни ошибку и как её исправить.
```

## Часть 5: Комбинации — мощный подход

### @Files + @Terminal

```
@Files: main.py, database.py
@Terminal

Ошибка возникает при запуске main.py.
Проанализируй код и вывод ошибки.
Найди причину и предложи решение.
```

### @Folder + @Files

```
@Folder: src/models
@Files: config.py

Добавь новую модель Product, следуя стилю
существующих моделей. Используй конфиг из config.py.
```

## Часть 6: Практика

### Упражнение 1: @Files

1. Создай файл `test_context.py`:

```python
def greet(name):
    return f"Hello, {name}!"

def calculate(a, b):
    return a + b
```

2. В Continue напиши:

```
@Files: test_context.py

Добавь функцию multiply(a, b), которая возвращает произведение.
Сделай в том же стиле, что и calculate.
```

### Упражнение 2: @Terminal

1. В терминале VS Code (`Ctrl+``) запусти:

```bash
python -c "print(1/0)"
```

2. Увидишь ошибку `ZeroDivisionError`

3. В Continue напиши:

```
@Terminal

Объясни эту ошибку простыми словами.
```

### Упражнение 3: Комбинация

1. Создай файл `app.py`:

```python
from flask import Flask
app = Flask(__name__)

@app.route('/')
def hello():
    return "Hello World!"

if __name__ == '__main__':
    app.run()
```

2. Попробуй запустить (если нет Flask, будет ошибка)

3. В Continue напиши:

```
@Files: app.py
@Terminal

Помоги запустить это приложение.
Что нужно установить? Как запустить?
```

## Часть 7: Важные советы

### 💡 Совет 1: Не перегружай контекст

```
❌ @Files: file1.py, file2.py, file3.py, ..., file20.py
   → ИИ запутается

✅ @Files: main.py, utils.py
   → ИИ сфокусируется
```

### 💡 Совет 2: Проверяй, что добавил

После добавления @Files или @Folder:
1. Кликни на "Контекст" внизу
2. Убедись, что нужные файлы там
3. Удали лишнее (крестик ✕)

### 💡 Совет 3: Локальные модели думают дольше

```
Если используешь Ollama (4GB/16GB GPU):
- RAG и контекст обрабатываются локально
- Чем больше файлов, тем дольше ответ
- API (Groq) обычно быстрее при большом контексте
```
