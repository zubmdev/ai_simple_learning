## Часть 1: Как Cline получает контекст

### Что «видит» агент?

```text
Когда ты отправляешь задачу в Cline, агент видит:

1. Текст задачи (промпт)
2. Всё, что ты приложил через @-упоминания
3. Файлы, которые он сам решит прочитать по ходу работы
   (каждое чтение — токены из твоего бюджета)
```

Пункты 1 и 2 контролируешь ты. Пункт 3 — агент, но ты можешь сделать его работу короче, дешевле и точнее: **назвав нужные файлы сразу**.

```text
Правило дня: агент не телепат. Всё, что важно — назови.
```

### 🛠️ Уровни доступа

Всё ниже работает на любом уровне:

| Уровень | Железо / доступ | Модель |
|---------|------------------|--------|
| 1 | CPU + бесплатный API (Groq) | `openai/gpt-oss-20b` |
| 2 | 4GB GPU + Ollama | `qwen3.5:2b` |
| 3 | 16GB GPU + Ollama | `gpt-oss:20b` |

*Проверено: 2026-10-24*

## Часть 2: Называем файлы в тексте задачи

Самый простой способ — написать путь к файлу прямо в промпте.

### ❌ Плохо

```text
Добавь валидацию email в функцию create_user.
```

Агент не знает, где `create_user`. Он начнёт искать по проекту — это время, токены и шанс ошибиться.

### ✅ Хорошо

```text
В файле src/services/user_service.py добавь валидацию email
в функцию create_user. Если email невалидный — ValueError.
Больше ничего не меняй.
```

### Ещё примеры

```text
В models.py и database.py: создай функцию get_user_by_email
в database.py, используя модель User из models.py.
```

```text
Перепиши функцию process_data из old_code.py,
следуя стилю из new_structure.py.
```

## Часть 3: @-упоминания — прикрепляем файлы

### Как это работает

```text
1. Поставь @ в поле задачи в Cline — откроется меню
2. Начни печатать имя файла или папки — выбери из списка
3. Над полем появится «пилюля» — файл прикреплён к задаче
4. Лишнюю пилюлю сними крестиком ✕
```

В меню, кроме файлов и папок проекта, есть ещё:
- **Problems** — список ошибок из редактора
- **Terminal** — свежий вывод терминала (подробнее в Дне 4)
- **URL** — содержимое веб-страницы

### Примеры

```text
@src/services/user_service.py

Добавь валидацию email в функцию create_user.
Если email невалидный, выбрось ValueError.
```

```text
@src/models
@config.py

Добавь новую модель Product, следуя стилю существующих
моделей. Настройки подключения возьми из config.py.
```

💡 Пилюли над полем — это твой чек-лист перед отправкой. Убедись, что прикрепил нужное и ничего лишнего.

## Часть 4: Папка целиком

### Когда прикреплять папку?

```text
✅ Когда нужно понять структуру модуля
✅ Когда файлы в папке тесно связаны
✅ Когда не знаешь, какие именно файлы нужны

❌ Когда папка очень большая (50+ файлов)
❌ Когда нужны только 1–2 файла — назови их по имени
```

### Пример

```text
@src/api

Объясни, как устроены эти API endpoints.
Какой паттерн используется?
```

Папка — это сразу много токенов. Прикрепляй её осознанно: сначала попробуй 1–2 файла, и только если их мало — раскрывай папку.

## Часть 5: 🛠️ Практика

### Упражнение 1: путь в тексте задачи

1. Создай файл `test_context.py`:

```python
def greet(name):
    return f"Hello, {name}!"

def calculate(a, b):
    return a + b
```

2. Открой Cline и напиши:

```text
В файле test_context.py добавь функцию multiply(a, b),
которая возвращает произведение. Сделай в том же стиле,
что и calculate. Больше ничего не меняй.
```

### Упражнение 2: @-упоминание

1. Тот же файл, но теперь прикрепи его через @: поставь `@` в поле задачи и выбери `test_context.py`.

2. Напиши:

```text
@test_context.py

Добавь функцию divide(a, b), которая делит a на b
и выбрасывает ZeroDivisionError при b == 0.
```

3. Сравни: оба способа работают. Путь в тексте — быстрее для одного файла, @ — удобнее, когда файлов несколько.

### Упражнение 3: обзор папки

1. Открой любой свой проект в VS Code.
2. Прикрепи папку с кодом через @ и напиши:

```text
Объясни простыми словами:
1. Что делает этот код?
2. Какие основные функции?
3. Какие зависимости между файлами?
```

## Часть 6: Важные советы

### 💡 Совет 1: Не перегружай контекст

```text
❌ 20 файлов через @ — агент запутается, бюджет сгорит
✅ 2–3 файла, названные по именам — агент сфокусируется
```

### 💡 Совет 2: Длинный чат — враг бюджета

```text
Каждое сообщение в задаче добавляет токены в окно.
Если индикатор контекста почти заполнен:
- Начни новую задачу (New Task)
- Приложи к ней только нужные файлы
```

### 💡 Совет 3: Локальная модель + большой контекст = медленно

```text
Если используешь Ollama (4GB/16GB GPU):
- Чем больше файлов, тем дольше ответ
- API (Groq) обычно быстрее при большом контексте
```
