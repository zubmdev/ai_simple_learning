### Шаг 2: Создай файл `todo.py`

```python
import json
import os

TODO_FILE = "todos.json"

def load_todos():
    if os.path.exists(TODO_FILE):
        with open(TODO_FILE, 'r') as f:
            return json.load(f)
    return []

def save_todos(todos):
    with open(TODO_FILE, 'w') as f:
        json.dump(todos, f, indent=2)

def add_todo(text):
    todos = load_todos()
    todos.append({"text": text, "done": False})
    save_todos(todos)
    print(f"✅ Added: {text}")

def list_todos():
    todos = load_todos()
    if not todos:
        print("No todos yet!")
        return
    for i, todo in enumerate(todos, 1):
        status = "✓" if todo["done"] else " "
        print(f"{i}. [{status}] {todo['text']}")

def complete_todo(index):
    todos = load_todos()
    if 0 < index <= len(todos):
        todos[index - 1]["done"] = True
        save_todos(todos)
        print(f"✅ Completed: {todos[index - 1]['text']}")
    else:
        print("❌ Invalid index")

def main():
    print("📝 Todo CLI")
    print("Commands: add <text>, list, complete <num>, exit")

    while True:
        command = input("\n> ").strip().split(maxsplit=1)

        if not command:
            continue

        if command[0] == "exit":
            print("Goodbye!")
            break
        elif command[0] == "add" and len(command) > 1:
            add_todo(command[1])
        elif command[0] == "list":
            list_todos()
        elif command[0] == "complete" and len(command) > 1:
            complete_todo(int(command[1]))
        else:
            print("Unknown command")

if __name__ == "__main__":
    main()
```

## Часть 5: Пишем первый AGENTS.md

### Шаг 1: Создай файл

Создай файл `AGENTS.md` в **корне проекта** — рядом с `todo.py`, не в подпапке.

### Шаг 2: Вставь скелет и подстрой под свой проект

```markdown
# AGENTS.md

## Язык
Отвечай по-русски.

## Проект
Консольный todo-список на Python. Весь код в todo.py,
данные хранятся в todos.json.
Файл создан в октябре 2026 в рамках курса Vibe Coding.

## Стиль кода
Python 3.11+. Всегда type hints. Docstring для публичных функций.
```

### Шаг 3: Заполни своими словами

Правила должны быть короткими и императивными — как приказ, а не как эссе. Проверь каждое правило вопросом: «Это верно всегда, для любой задачи в этом проекте?» Если нет — это не правило, а разовое указание, ему место в задаче.

## Часть 6: Проверяем, что агент следует правилам

Момент истины. Начни **новую задачу** в Cline (не продолжай старый чат — правила должны примениться с чистого листа) и напиши:

```text
Добавь функцию search_todos(query), которая возвращает
задачи, в тексте которых встречается подстрока query.
Больше ничего не меняй.
```

Теперь сверь ответ агента с правилами:

| Правило | Проверка | ✅/❌ |
|---------|----------|-------|
| Язык | Ответ на русском | |
| Стиль | У функции type hints и docstring | |
| Фокус | Изменён только todo.py | |
| Работа | Ты запустил `python todo.py` и поиск работает | |

```bash
python todo.py
> add work:Call mom
> search Call
```

### Если агент нарушил правило

Не ругай агента — правило просто ещё не сформулировано жёстко. Например, если он написал без type hints, добавь в `AGENTS.md` явное «Всегда type hints» и повтори задачу. В Неделе 4 научимся чинить правила системно.
