## Часть 1: Проблема чужого кода

```
Ты открыл проект:

- Никаких комментариев
- Код 3-летней давности

Вопрос: "Что это вообще делает?! 😱"
```

### Старый подход vs Vibe Coding

| Старый подход | Vibe Coding |
|---------------|-------------|
| Читать каждый файл | Попросить ИИ объяснить |
| Гуглить каждую функцию | Спросить у ИИ |
| Тратить часы | Тратить минуты |
| Разочарование | Понимание |

## Часть 2: Магический промпт

### Промпт для понимания кода

```
@Files: [файлы проекта]

Объясни мне этот код так, будто я 10-летний.
Не используй технический жаргон.
Объясни:
1. Что делает код в целом
2. Какие основные функции
3. Как данные проходят через код
4. Какие библиотеки используются и зачем
```

### Почему это работает

```
✅ "как 10-летний" → ИИ упрощает объяснение
✅ "без жаргона" → ИИ избегает сложных терминов
✅ Структурированный запрос → ИИ даёт структурированный ответ
```

## Часть 3: Практика — разбираем реальный код

### Задание: Понять Python скрипт

**Шаг 1:** Создай файл `mystery_code.py`:

```python
import json
from pathlib import Path
from typing import Any

class DataProcessor:
    def __init__(self, source: str):
        self.source = Path(source)
        self._cache: dict[str, Any] = {}
    
    def load(self) -> dict:
        if self.source.name in self._cache:
            return self._cache[self.source.name]
        
        with open(self.source, 'r') as f:
            data = json.load(f)
        
        self._cache[self.source.name] = data
        return data
    
    def transform(self, data: dict, keys: list[str]) -> list[dict]:
        result = []
        for key in keys:
            if key in data:
                result.append({key: data[key]})
        return result
    
    def save(self, data: list[dict], output: str) -> None:
        with open(output, 'w') as f:
            json.dump(data, f, indent=2)

if __name__ == '__main__':
    processor = DataProcessor('input.json')
    data = processor.load()
    transformed = processor.transform(data, ['name', 'email'])
    processor.save(transformed, 'output.json')
```

**Шаг 2:** В Continue напиши:

```
@Files: mystery_code.py

Объясни мне этот код так, будто я 10-летний.
Не используй технический жаргон.

Ответь на вопросы:
1. Что делает этот код в целом?
2. Что такое DataProcessor?
3. Что делает функция load?
4. Что делает функция transform?
5. Что делает функция save?
6. Что такое _cache и зачем оно нужно?
```

**Шаг 3:** Прочитай объяснение ИИ

ИИ объяснит простыми словами:
- Класс — это как "машина" с кнопками (функциями)
- load — загружает данные из файла
- transform — преобразует данные
- save — сохраняет результат
- _cache — запоминает, чтобы не читать дважды

## Часть 6: Типичные ошибки

### ❌ Ошибка 1: Не давать контекст

```
Промпт: "Объясни код"

ИИ: "Какой код? Я не вижу файлов."
```

**Решение:** Всегда добавляй `@Files` или `@Folder`

### ❌ Ошибка 2: Давать слишком много

```
@Folder: .  ← 100 файлов в проекте

ИИ: *обрабатывает 5 минут*
ИИ: "Слишком много информации, уточни запрос"
```

**Решение:** Добавляй только нужные папки (`@Folder: src`)

### ❌ Ошибка 3: Слишком общий вопрос

```
Промпт: "Что это?"

ИИ: "Что именно? Уточни вопрос."
```

**Решение:** Задавай конкретные вопросы
