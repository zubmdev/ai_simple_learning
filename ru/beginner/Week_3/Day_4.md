## Часть 1: Почему терминал важен

### Типичная ситуация

```text
Ты запускаешь код:
$ python main.py

Получаешь ошибку:
Traceback (most recent call last):
  File "main.py", line 42, in <module>
    result = calculate(x, y)
  File "main.py", line 15, in calculate
    return a / b
ZeroDivisionError: division by zero

Вопрос: "Что делать?! 😱"
```

### Старый подход vs Vibe Coding

| Старый подход | Vibe Coding |
|---------------|-------------|
| Копировать ошибку → гуглить | Вставить ошибку агенту → спросить |
| Читать Stack Overflow 30 мин | Разобраться за минуты |
| Пробовать решения наугад | Понять причину и исправить |

Ошибка из терминала — это готовый контекст: в traceback написано, какой файл, какая строка и что пошло не так. Твоя работа — доставить его агенту целиком.

## Часть 2: Три способа передать ошибку

### Способ 1: Вставить текст в задачу

```text
Запустил python main.py, падает с ошибкой:

Traceback (most recent call last):
  File "main.py", line 15, in calculate
    return a / b
ZeroDivisionError: division by zero

Объясни ошибку простыми словами и предложи исправление.
```

Работает всегда и везде. Вставляй traceback **целиком** — последние строки без начала бесполезны.

### Способ 2: @terminal

```text
@terminal

Объясни ошибку и как её исправить.
```

`@terminal` прикрепляет свежий вывод интегрированного терминала VS Code. Порядок такой:

```text
1. Запусти код в терминале VS Code (Ctrl+`)
2. Код упал с ошибкой — не закрывай и не очищай терминал!
3. Поставь @ в поле задачи Cline и выбери Terminal
4. Напиши промпт
```

### Способ 3: Агент запускает команду сам

```text
Запусти python main.py, посмотри на ошибку
и предложи исправление.
```

Cline покажет команду и **спросит одобрение** перед запуском. Одобришь — агент сам увидит вывод и сам предложит перезапуск после исправления.

🚨 **Безопасность:** читай каждую команду перед одобрением. Непонятная команда — сначала спроси: «Что делает эта команда?» Одобряй только то, что понимаешь.

### 🛠️ Уровни доступа

Всё ниже работает на любом уровне:

| Уровень | Железо / доступ | Модель |
|---------|------------------|--------|
| 1 | CPU + бесплатный API (Groq) | `openai/gpt-oss-20b` |
| 2 | 4GB GPU + Ollama | `qwen3.5:2b` |
| 3 | 16GB GPU + Ollama | `gpt-oss:20b` |

## Часть 3: 🛠️ Практика — исправляем ошибки

### Упражнение 1: ZeroDivisionError (способ 1 — вставка)

**Шаг 1:** Создай файл `error_example.py`:

```python
def divide(a, b):
    return a / b

def calculate_average(numbers):
    total = sum(numbers)
    count = len(numbers)
    return divide(total, count)

# Тестируем
result = calculate_average([])
print(f"Average: {result}")
```

**Шаг 2:** Запусти в терминале:

```bash
python error_example.py
```

Увидишь `ZeroDivisionError: division by zero`.

**Шаг 3:** Скопируй traceback целиком и вставь в задачу:

```text
Запустил error_example.py, падает с ошибкой:
<вставь traceback>

Почему она возникает? Как исправить код,
чтобы он не падал на пустом списке?
```

**Шаг 4:** Ожидаемый итог:

- Причина: пустой список → `count == 0` → деление на ноль
- Исправление: проверка `if count == 0` перед делением
- Примени исправление (агент предложит дифф), запусти снова — ошибки нет

### Упражнение 2: ImportError (способ 2 — @terminal)

**Шаг 1:** Создай файл `import_error.py`:

```python
from nonexistent_module import some_function

result = some_function()
print(result)
```

**Шаг 2:** Запусти в терминале:

```bash
python import_error.py
```

**Шаг 3:** Не очищая терминал, прикрепи вывод через @ и напиши:

```text
@terminal

Что означает эта ошибка? Как исправить?
```

### Упражнение 3: SyntaxError (способ 3 — агент запускает сам)

**Шаг 1:** Создай файл `syntax_error.py` с ошибкой:

```python
def greet(name
    print(f"Hello, {name}!")

greet("World")
```

**Шаг 2:** В Cline напиши:

```text
В файле syntax_error.py есть синтаксическая ошибка.
Запусти его, найди ошибку, покажи исправление
и перезапусти, чтобы убедиться, что всё работает.
```

**Шаг 3:** Одобри команды агента (прочитай каждую!) и проверь результат: скрипт печатает приветствие без ошибок.

## Часть 4: Комбинация — код + лог

Когда ошибка в конкретном файле, дай агенту и код, и вывод:

```text
@main.py

Запустил main.py, падает с ошибкой:
<вставь traceback>

Проанализируй: в каком месте ошибка? Как исправить?
Исправь и объясни, что было не так.
```

```text
Правило: лог рассказывает, ЧТО сломалось.
Код рассказывает, ПОЧЕМУ. Агенту нужно и то, и другое.
```

## Часть 5: Логи и ошибки редактора

### Лог-файлы

Если программа пишет лог в файл — прикрепи его как обычный файл:

```text
@logs/app.log

Найди в логе последние ошибки и объясни,
что происходит. Укажи время и причину каждой.
```

Большой лог? Попроси сначала найти ошибки, и только потом прикрепляй строки вокруг них — не весь файл.

### @problems — ошибки из редактора

VS Code подчёркивает проблемы красным ещё до запуска. Поставь `@` и выбери **Problems** — агент увидит список ошибок редактора:

```text
@problems

Разбери ошибки из списка и предложи исправления,
начиная с самой серьёзной.
```

## Часть 6: Продвинутые техники

### Техника 1: Пошаговый разбор traceback

```text
Разбери traceback по шагам:
1. Какой файл вызвал ошибку?
2. Какая функция?
3. На какой строке?
4. Какой вызов привёл к этой строке?

Покажи цепочку вызовов.
```

### Техника 2: Поиск root cause

```text
@main.py

Ошибка может быть не причиной, а следствием.
Найди root cause — настоящую причину, — а не только место падения.
```

## Часть 7: Типичные ошибки и решения

### ModuleNotFoundError

```text
Промпт: @terminal — Что означает ошибка? Какой пакет установить?

Ответ агента: pip install requests
```

💡 Установку пакетов агент должен делать только с твоего одобрения — читай, что именно он ставит.

### FileNotFoundError

```text
Промпт:
@main.py

Запустил main.py — FileNotFoundError. Проверь пути в коде.

Ответ агента: проблема в строке 15, путь должен быть
'./data/file.txt', а не 'data/file.txt'
```

### PermissionError

```text
Промпт: @terminal — Нет прав доступа. Что делать?

Ответ агента:
1. Проверь права: ls -la file.txt
2. Измени права: chmod +x file.txt
3. sudo — только если понимаешь, что делаешь
```
