## Часть 1: Почему терминал важен

### Типичная ситуация

```
Ты запускаешь код:
$ python main.py

Получаешь ошибку:
Traceback (most recent call last):
  File "main.py", line 42, in <module>
    result = calculate(x, y)
  File "main.py", line 15, in calculate
    return a / b
ZeroDivisionError: division by zero

Вопрос: "Что делать?! 😱"
```

### Старый подход vs Vibe Coding

| Старый подход | Vibe Coding |
|---------------|-------------|
| Копировать ошибку → гуглить | @Terminal → спросить ИИ |
| Читать Stack Overflow 30 мин | Получить ответ за 30 сек |
| Пробовать разные решения | Получить точное решение |

## Часть 2: @Terminal в Continue.dev

### Как это работает

```
Когда ты пишешь @Terminal:

1. ИИ берёт последние N строк из терминала
2. Анализирует ошибку
3. Находит причину
4. Предлагает решение
```

### Способы использования

#### Способ 1: Вручную

```
@Terminal

Объясни ошибку и как её исправить.
```

#### Способ 2: Через иконку

1. Нажми **📎** (скрепка) в поле ввода
2. Выбери **"Terminal Output"**
3. Напиши промпт

## Часть 3: Практика — исправляем ошибки

### Упражнение 1: ZeroDivisionError

**Шаг 1:** Создай файл `error_example.py`:

```python
def divide(a, b):
    return a / b

def calculate_average(numbers):
    total = sum(numbers)
    count = len(numbers)
    return divide(total, count)

# Тестируем
result = calculate_average([])
print(f"Average: {result}")
```

**Шаг 2:** Запусти в терминале:

```bash
python error_example.py
```

**Шаг 3:** Увидишь ошибку:

```
ZeroDivisionError: division by zero
```

**Шаг 4:** В Continue напиши:

```
@Terminal

Объясни ошибку простыми словами.
Почему она возникает?
Как исправить код, чтобы он не падал?
```

**Шаг 5:** ИИ объяснит:

- Проблема: пустой список → деление на 0
- Решение: добавить проверку на пустой список
- Код: `if count == 0: return 0`

## Часть 4: Комбинация @Terminal + @Files

### Когда использовать

```
✅ Когда ошибка в конкретном файле
✅ Когда нужно понять контекст ошибки
✅ Когда ИИ должен увидеть и код, и ошибку
```

### Пример

```
@Files: main.py, utils.py
@Terminal

Код падает при запуске main.py.
Проанализируй:
1. В каком файле ошибка?
2. Какая функция вызывает проблему?
3. Как исправить?

Исправь код и объясни, что было не так.
```

## Часть 5: Продвинутые техники

### Техника 1: Пошаговый анализ

```
@Terminal

Проанализируй traceback:
1. Какой файл вызвал ошибку?
2. Какая функция?
3. На какой строке?
4. Какой вызов привёл к этой строке?

Покажи chain of calls.
```

### Техника 2: Поиск root cause

```
@Files: [все файлы проекта]
@Terminal

Ошибка: [вставь ошибку]

Это может быть не сама проблема, а следствие.
Найди root cause — настоящую причину ошибки.
```

### Техника 3: Предотвращение ошибок

```
@Files: main.py

Проверь код на потенциальные ошибки:
- Division by zero
- None/undefined values
- Index out of range
- Type errors

Покажи, где могут быть проблемы и как их предотвратить.
```

## Часть 7: Типичные ошибки и решения

### Ошибка 1: ModuleNotFoundError

```
Ошибка: ModuleNotFoundError: No module named 'requests'

Решение через ИИ:
@Terminal
Как установить этот модуль?

ИИ: pip install requests
```

### Ошибка 2: FileNotFoundError

```
Ошибка: FileNotFoundError: [Errno 2] No such file or directory

Решение через ИИ:
@Files: main.py
@Terminal
Файл не найден. Проверь пути в коде.

ИИ: Проблема в строке 15. Путь должен быть './data/file.txt'
```

### Ошибка 3: PermissionError

```
Ошибка: PermissionError: [Errno 13] Permission denied

Решение через ИИ:
@Terminal
Нет прав доступа. Что делать?

ИИ: 
1. Проверь права: ls -la file.txt
2. Измени права: chmod +x file.txt
3. Или запусти с sudo (если безопасно)
```
