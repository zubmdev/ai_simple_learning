#### 📜 Проект 1: ASCII Арт Генератор (Недели 1-2)

**Что это:** Программа, которая превращает текст в красивые "рисунки" из символов.

**Что делает:**
- Спрашивает ваше имя
- Генерирует ASCII-арт — "картинку" из букв и символов
- Позволяет выбрать стиль (блочный, наклонный, баннер)
- Сохраняет результат в файл

**Какие задачи решает:**
- Создание уникальных подписей для email или соцсетей
- Генерация логотипов для презентаций
- Просто весёлое приложение для друзей

**Технологии:** Python

---

#### ✅ Проект 2: Todo CLI — Консольный планировщик (Неделя 3)

**Что это:** Приложение для управления задачами прямо в терминале.

**Что делает:**
- Добавляет задачи с категориями (работа, личное, покупки)
- Устанавливает приоритеты (высокий, средний, низкий)
- Показывает список с цветовой подсветкой
- Сохраняет задачи между запусками

**Какие задачи решает:**
- Быстрое планирование дня без лишних приложений
- Организация задач по категориям
- Приоритизация — что делать первым

**Технологии:** Python, JSON

---

#### 📱 Проект 3: To-Do веб-приложение (Неделя 6)

**Что это:** Красивое веб-приложение для задач, работает в браузере.

**Что делает:**
- Добавление задач одним кликом
- Отметка выполненных задач
- Удаление задач
- Автосохранение в браузере (задачи не пропадут после закрытия)
- Работает на компьютере и телефоне

**Какие задачи решает:**
- Ежедневное планирование
- Список покупок
- Трекер привычек
- Можно поделиться с друзьями (если опубликовать на GitHub Pages)

**Технологии:** HTML, CSS, JavaScript

## 📖 Как пользоваться курсом

Курс написан в формате **Markdown** (файлы `.md`). Вот как его читать.

### Рекомендация: VS Code

VS Code — редактор, который будем использовать весь курс. Отлично подходит для Markdown!

**Шаги:**
1. Установите VS Code → [code.visualstudio.com](https://code.visualstudio.com)
2. Откройте файл: `File` → `Open File...` → выберите файл `.md`
3. Предпросмотр Markdown: `Ctrl + Shift + V` (Windows/Linux) или `Cmd + Shift + V` (macOS)

### Рекомендуемый плагин

**Markdown Preview Enhanced:**
1. Откройте Extensions: `Ctrl + Shift + X`
2. Найдите: `Markdown Preview Enhanced`
3. Установите

**Добавляет:**
- 📑 Оглавление
- 🎨 Подсветку синтаксиса
- 📄 Экспорт в PDF

### Альтернативные редакторы

### Если застрял

1. **Спроси ИИ-ассистента:** "Я застрял на [шаг]. Объясни простыми словами, что делать."

   - VS Code: https://code.visualstudio.com/docs
   - Cline: https://cline.bot
   - Ollama: https://ollama.ai/docs

   - Ollama Discord: https://discord.gg/ollama

### Если ошибка

1. Скопируй текст ошибки
2. Вставь в ИИ-ассистента с вопросом: "Вот ошибка: [ошибка]. Как исправить?"

1. Попроси ИИ: "Объясни это как для 5-летнего ребёнка."
2. Или: "Объясни простыми словами, без технических терминов."
3. Или: "Дай пример из жизни, чтобы я понял."
