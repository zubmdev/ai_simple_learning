# Неделя 5: MCP — инструменты, одобрения и безопасность 🔌

**Трек:** 🌱 Начинающий (Beginner)

Ты уже умеешь давать ИИ контекст из файлов и правил `AGENTS.md`. Но у агента по-прежнему нет доступа к базам данных, внешним сервисам и папкам вне проекта. MCP (Model Context Protocol) — открытый стандарт, который подключает к агенту инструменты: базы, файлы, API. А вместе с инструментами появляется главное правило недели: **каждый вызов инструмента одобряешь ты**.

> 🚨 Если ты начинал курс на старом стеке: конфигурация MCP теперь живёт в Cline, в файле `cline_mcp_settings.json`. Старый способ через `~/.continue/config.json` (Continue.dev) больше не используется — секцию `mcpServers` оттуда придётся перенести в настройки Cline вручную.

## 🧠 Главная идея недели

```text
❌ Без MCP:  ИИ работает только с текстом и файлами проекта
✅ С MCP:    ИИ вызывает инструменты — базы, файлы, внешние API
🔒 С правилами: каждый вызов инструмента проходит через твоё «Да»
```

MCP — это «USB-порт» для ИИ-агента. Подключил сервер — у агента появились новые инструменты. Но у каждого инструмента есть предохранитель: одобрение. Эта неделя учит и подключать, и не терять контроль.
