# Неделя 5: Введение в MCP (Model Context Protocol) 🔧

**Трек:** 🌱 Начинающий (Beginner)

Ты уже умеешь работать с контекстом из файлов. Но что, если нужно дать ИИ доступ к базе данных, веб-сервисам или файловой системе? MCP — это протокол, который "даёт ИИ руки" (инструменты) и "глаза" (доступ к внешним данным).

## 🧠 Главная идея недели

```
❌ Без MCP: ИИ может только генерировать текст на основе твоих файлов
✅ С MCP: ИИ может читать базы, файлы, API и выполнять действия
```

MCP — это "USB-порт" для ИИ. Через него можно подключить базу данных, файловую систему, веб-сервис и многое другое.
