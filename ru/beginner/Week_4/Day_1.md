# День 1: Правила для агента — что кладём в AGENTS.md 📋

**Трек:** 🌱 Начинающий | **Время:** 30 минут

---

## 🎯 Цель дня

Научиться писать правила, которые агент выполняет в каждой задаче, — и отличать правила от мусора, который только раздувает контекст.

---

## Часть 1: Проблема — ты повторяешься

### Ситуация

Каждый чат начинается одинаково:

```text
Ты: "Отвечай по-русски. Используй type hints. Не пиши очевидных комментариев."
Ты: "Отвечай по-русски. Используй type hints. Не пиши очевидных комментариев."
Ты: "...уже третий раз сегодня"
```

### Решение: правила в AGENTS.md

```text
Записал правила ОДИН РАЗ в AGENTS.md
→ агент читает их в начале КАЖДОЙ задачи
→ ты больше не повторяешь
```

Агенты ищут файл `AGENTS.md` в корне проекта автоматически. Это стандарт, который понимают Cline, OpenCode и большинство современных агентов.

---

## Часть 2: Аналогия — памятка для нового сотрудника

```text
Представь: ты нанял сильного разработчика, но он ничего
не знает о твоём проекте.

Плохо: каждый день заново рассказываешь ему правила.
Хорошо: повесил на стену памятку из 15 пунктов —
        он прочитал утром и следует ей весь день.

AGENTS.md = эта памятка.
Промпт = конкретное задание на день.
```

Смешивать нельзя: «как у нас принято работать» — в памятку, «сделай сегодня то-то» — в задание.

---

## Часть 3: Что belongs, а что нет

### ✅ Кладём в AGENTS.md

| Правило | Пример |
|---------|--------|
| Язык ответов | «Отвечай по-русски» |
| Стиль кода проекта | «Python 3.11+, type hints, функции до 30 строк» |
| Структура проекта | «Код в todo.py, данные в todos/» |
| Как проверять результат | «После изменений запускай: `python todo.py`» |
| Запреты | «Не удаляй файлы без подтверждения», «Секреты — только в .env» |

### ❌ НЕ кладём в AGENTS.md

| Мусор | Почему нет |
|-------|-----------|
| API-ключи и пароли | Никогда. Только `.env` |
| Конкретное задание | Это в промпт: «правила» верны всегда, задание — один раз |
| Большие документы и туториалы | Раздувает контекст (см. Неделя 3: Context is King) |
| Противоречивые правила | «Пиши кратко» + «Объясняй каждую строку» — агент запутается |
| То, что верно не всегда | «Всегда используй FastAPI» в проекте без API — ложь |

### 🚨 Тест одного вопроса

Перед каждым правилом спроси: **«Это верно всегда, в любой задаче этого проекта?»**
- Да → в `AGENTS.md`.
- Нет → это часть промпта конкретной задачи.

💡 Если проект огромный и ты не знаешь, где лежит нужный код, поисковый режим агента по репозиторию всё ещё выручает. Но сначала дай агенту правила и точные файлы — это дешевле и надёжнее, чем поиск вслепую.

## Часть 4: Практика — аудит AGENTS.md

### 🛠️ Уровни доступа

Всё ниже работает на любом уровне:

| Уровень | Железо / доступ | Модель |
|---------|------------------|--------|
| 1 | CPU + бесплатный API (Groq) | `openai/gpt-oss-20b` |
| 2 | 4GB GPU + Ollama | `qwen3.5:2b` |
| 3 | 16GB GPU + Ollama | `gpt-oss:20b` |

*Проверено: 2026-10-24*

В конце Недели 3 ты создал первый `AGENTS.md`. Теперь проведём аудит.

**Шаг 1:** Открой проект из Недели 3 (или свой) в VS Code.

```bash
code .
```

**Шаг 2:** Перечитай `AGENTS.md` и пройдись по строкам с тестом одного вопроса. Выпиши строки-мусор: задания, длинные объяснения, противоречия.

**Шаг 3:** Приведи файл к такому виду (подстрой под свой проект):

```markdown
# AGENTS.md

## Язык
Отвечай по-русски.

## Проект
Консольный todo-список на Python. Код в todo.py, данные в todos/*.json.

## Стиль кода
Python 3.11+. Всегда type hints. Docstring для публичных функций.
Функции до 30 строк. Без очевидных комментариев.

## Как проверять
После любых изменений запускай: python todo.py
Задача считается выполненной, только если команда прошла без ошибок.

## Нельзя
- Не выполняй команды удаления и установку пакетов без моего явного подтверждения.
- Секреты никогда не попадают в код — только в .env.
```

Заметь: 6 разделов, меньше 20 строк, каждая строка проходит тест «верно всегда».

**Шаг 4:** Проверь, что правила действуют. Открой новый чат с агентом и напиши:

```text
Добавь функцию show_stats, которая печатает количество задач
по категориям. Не меняй больше ничего.
```

## Часть 5: Как понять, что правила работают

Сверь ответ агента с правилами:

| Правило | Проверка | ✅/❌ |
|---------|----------|-------|
| Язык | Ответ на русском | |
| Стиль | Есть type hints, нет очевидных комментариев | |
| Проверка | Агент сам запустил `python todo.py` | |
| Запреты | Ничего не удалил, ничего не ставил | |

Если агент нарушает правило:
1. Правило слишком длинное — сожми в одну императивную фразу.
2. Правила противоречат друг другу — оставь одно.
3. Правило не про «всегда» — перенеси в промпт.
