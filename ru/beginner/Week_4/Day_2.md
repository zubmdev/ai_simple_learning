## Часть 1: Как работает @Codebase

### Процесс

```
1. Ты пишешь @Codebase
2. Continue ищет по всему проекту
3. Находит релевантные куски
4. Отдаёт ИИ как контекст
5. ИИ отвечает
```

### Когда использовать

```
✅ Не знаешь, где нужный код
✅ Нужно найти все использования функции
✅ Хочешь понять архитектуру
✅ Ищешь паттерны в проекте

❌ Знаешь конкретный файл (@Files быстрее)
❌ Очень большой проект (1000+ файлов)
❌ Нужна максимальная точность
```

## Часть 2: Практика — поиск в проекте

### Подготовка

Используем проект из вчера или создай новый:

```bash
mkdir codebase-test
cd codebase-test
```

Создай структуру:

```
codebase-test/
├── main.py
├── api/
│   ├── users.py
│   ├── products.py
│   └── orders.py
├── models/
│   ├── user.py
│   ├── product.py
│   └── order.py
├── services/
│   ├── email.py
│   ├── payment.py
│   └── notification.py
└── utils/
    ├── validators.py
    └── helpers.py
```

## Часть 4: Комбинация @Codebase с другими инструментами

### @Codebase + @Terminal

```
@Codebase
@Terminal

Ошибка возникает при вызове API endpoint.
Найди в коде:
1. Какой endpoint вызывает проблему?
2. Какая функция обрабатывает?
3. В чём может быть причина?

Используй вывод терминала для понимания ошибки.
```

### @Codebase + @Files

```
@Codebase
@Files: config.py

Найди все места, где используются настройки из config.py.
Проверь, что все настройки используются корректно.
```

## Часть 5: Оптимизация для больших проектов

### Проблема

```
Большой проект (500+ файлов):
- Индексация занимает время
- Поиск медленный
- Результаты могут быть неточными
```

### Решения

#### 1. Ограничь поиск папкой

```
@Folder: src/api

Вместо @Codebase для всего проекта.
```

#### 2. Используй конкретные вопросы

```
❌ "@Codebase что делать?"
✅ "@Codebase где функция process_payment?"
```

#### 3. Разбей на части

```
@Codebase

Только в папке services/ найди:
- Функции работы с базой данных
- Функции отправки сообщений
- Функции обработки файлов
```

#### 4. Для локальных моделей

```
Ollama (4GB/16GB GPU):
- RAG работает, но медленнее
- Начни с проектов до 100 файлов
- Для больших проектов используй API (Groq)
```

## Часть 6: Практический кейс — рефакторинг

### Ситуация

Нужно переименовать функцию во всём проекте.

### Старый подход

```
1. Ctrl+Shift+F (поиск по проекту)
2. Найти все использования
3. Переименовать вручную
4. Пропустить некоторые места
5. Получить ошибки при запуске
```

### Vibe Coding подход

```
@Codebase

Найди все использования функции get_user_data.
Переименуй в fetch_user_profile.
Покажи:
1. Сколько использований найдено
2. В каких файлах
3. Какие изменения нужны
4. Есть ли риски (разные контексты)

Предложи безопасный план переименования.
```
