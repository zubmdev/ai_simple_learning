## 🧠 Главная идея недели

```
❌ Раньше: Ты даёшь файлы вручную → ИИ отвечает
✅ Теперь: ИИ сам ищет файлы → ИИ отвечает в твоём стиле
```

RAG — это технология, которая позволяет ИИ "читать" весь проект и находить нужное. Rules — это инструкции, которые делают ИИ "персонализированным" под твой проект.

```
Если используешь Ollama (4GB/16GB GPU):

- Чем больше проект, тем дольше поиск
- API (Groq) быстрее при больших проектах
- Но локальные модели — приватные!

Совет: Начни с небольших проектов для RAG
```
