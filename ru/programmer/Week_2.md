## ⚡ TL;DR

### P.T.C.F. как спецификация

```
P - Persona (Роль): Ты — Senior разработчик
T - Task (Задача): Напиши функцию X + критерии приёмки («готово, когда...»)
C - Context (Контекст): Это для production API + релевантные файлы
F - Format (Формат): Структурированный вывод: дифф, JSON, тесты
```

### Когда что использовать

| Техника | Когда использовать |
|---------|-------------------|
| Zero-shot | Стандартные задачи, не важен стиль |
| Few-shot | Нужен специфический стиль, консистентность |
| CoT | Сложная логика, алгоритмы, дебаггинг — план до кода |
