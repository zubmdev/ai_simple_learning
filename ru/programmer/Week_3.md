## ⚡ TL;DR

### Бюджет контекста

```text
Контекст = всё, что модель видит прямо сейчас:
правила + задача + файлы + вывод команд + история чата

❌ Давать весь проект (100+ файлов)
✅ Называть точки входа и проверять, что агент прочитал
```

### Кто поставляет контекст

```text
1. Ты явно: приложи файлы или назови пути
2. Агент сам: читает файлы и запускает команды в цикле
3. Правила: AGENTS.md добавляет знания проекта в каждую задачу
```

### Best Practice

```text
Правило 3 файлов:
1. Файл, который правишь
2. Файл с зависимостями
3. Конфигурация (если нужно)
Остальное агент найдёт сам — но бюджет платишь ты.
```
