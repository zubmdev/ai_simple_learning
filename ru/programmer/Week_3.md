## ⚡ TL;DR

### Context Bloat

```
❌ Давать весь проект (100+ файлов)
✅ Давать только нужные файлы (1-5)
```

### Context Providers

| Provider | Use Case |
|----------|----------|
| `@Files: file.py` | Конкретные файлы |
| `@Folder: src/api` | Модуль/папка |
| `@Terminal` | Ошибки, вывод |

### Best Practice

```
Правило 3 файлов:
1. Файл, который правишь
2. Файл с зависимостями
3. Конфигурация (если нужно)
```
