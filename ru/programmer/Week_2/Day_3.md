# День 3: Chain of Thought (CoT) 🧠

**Трек:** 👨‍💻 Программист | **Время:** 25 минут

---

## 💡 Идея

Заставь AI рассуждать step-by-step перед ответом.

```
❌ Без CoT: AI даёт первый попавшийся ответ
✅ С CoT: AI анализирует, планирует, потом отвечает
```

---

## 🔬 Magic Phrases

```
"Думай пошагово" / "Think step-by-step"
"Проанализируй задачу перед написанием кода"
"Сначала опиши план, потом напиши код"
"Рассуждай вслух"
```

---

## 📋 Шаблон CoT промпта

```markdown
Задача: [описание]

Проанализируй step-by-step:

1. Какие подходы существуют для решения?
2. Какой подход оптимальный и почему?
3. Какие edge cases нужно учесть?
4. Какую архитектуру выбрать?
5. Напиши код с комментариями
```

---

## 🛠️ Примеры

### Для алгоритмов

```
Задача: Найти кратчайший путь в графе.

Рассуждай step-by-step:
1. Какие алгоритмы существуют? (BFS, Dijkstra, A*, Bellman-Ford)
2. Какой подходит для невзвешенного графа?
3. Опиши логику работы словами
4. Напиши pseudocode
5. Напиши Python реализацию
```

### Для дебаггинга

```
Код падает с ошибкой: [вставь traceback]

Проанализируй:
1. Что должен делать код?
2. Что происходит на самом деле?
3. В каком месте логика нарушена?
4. Почему это происходит?
5. Как исправить?
6. Напиши исправленный код
```

### Для оптимизации

```
Код работает медленно.

Проанализируй:
1. Где bottleneck?
2. Какая текущая сложность? (O notation)
3. Как можно оптимизировать?
4. Какие trade-offs?
5. Напиши оптимизированную версию
```

---

## 📊 Когда использовать CoT

| Задача | CoT нужен? |
|--------|------------|
| Простой CRUD | ❌ Нет |
| Сложный алгоритм | ✅ Да |
| Дебаггинг | ✅ Да |
| Архитектура | ✅ Да |
| Оптимизация | ✅ Да |
| Простой рефакторинг | ❌ Нет |
