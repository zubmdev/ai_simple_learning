## 📋 Структура debugging промпта

```markdown
## Контекст
Что делает код: [кратко]
Что ожидаю: [ожидаемое поведение]
Что получаю: [фактическое поведение]

## Ошибка
[Полный traceback]

## Код
[Релевантная часть кода]

## Что пробовал
1. [попытка 1]
2. [попытка 2]

## Окружение
- Python: 3.11
- OS: Ubuntu 22.04
- Библиотеки: [versions]
```

---

## ❌ Плохой промпт

```
Не работает. Помоги.
```

---

## ✅ Хороший промпт

```markdown
## Контекст
Парсю JSON из API и сохраняю в базу.
Ожидаю: словарь с данными
Получаю: JSONDecodeError

## Ошибка
```
json.decoder.JSONDecodeError: Expecting value: line 1 column 1 (char 0)
```

## Код
```python
import requests
response = requests.get('https://api.example.com/data')
data = json.loads(response.text)
```

## Что пробовал
1. Проверил URL в браузере — возвращает JSON
2. print(response.text) — пустая строка

Проанализируй проблему и предложи решение.
```

## 🔧 Продвинутые техники

### 1. AI Code Review (до запуска)

```
Проверь код на:
- Security vulnerabilities
- Performance issues
- Race conditions
- Memory leaks
- Best practices violations

[код]
```

### 2. Root Cause Analysis

```
Код работал вчера, сегодня упал.
Изменения: [что менял]

Проанализируй:
1. Какие изменения могли вызвать ошибку?
2. Какие зависимости обновились?
3. Что изменилось в окружении?
4. Как найти root cause?
```

### 3. Test Case Generation

```
Код должен обрабатывать:
- Пустой ввод
- None
- Неверный формат
- Unicode символы
- Очень длинные строки

Напиши pytest тесты для функции:
[код]
```

---

## 💡 Best Practices

| Практика | Почему |
|----------|--------|
| Полный traceback | AI видит stack trace |
| Минимальный пример кода | Не перегружай контекст |
| Указывай версии | Баги зависят от версий |
| Показывай что пробовал | AI не предложит то же самое |
