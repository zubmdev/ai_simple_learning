# День 2: Zero-shot vs Few-shot 🎯

**Трек:** 👨‍💻 Программист | **Время:** 20 минут

---

## 🔬 Zero-shot

**Определение:** Просишь агента выполнить задачу без примеров.

```
Напиши функцию для конвертации JSON в XML.
Type hints, docstring, 3 pytest-теста. Готово, когда тесты проходят.
```

**Когда использовать:**
- Стандартные задачи
- Не важен специфический стиль
- Быстрый прототип

---

## 🔬 Few-shot

**Определение:** Даёшь 1-3 примера для показа желаемого стиля.

```python
Напиши функцию в таком стиле:

Пример 1:
def read_file(path: str) -> str:
    """Читает файл и возвращает содержимое."""
    import logging
    logging.info(f"Reading: {path}")
    with open(path, 'r') as f:
        return f.read()

Пример 2:
def write_file(path: str, content: str) -> None:
    """Записывает содержимое в файл."""
    import logging
    logging.info(f"Writing: {path}")
    with open(path, 'w') as f:
        f.write(content)

Теперь напиши функцию append_to_file(path: str, content: str) -> None
в том же стиле. Готово, когда тесты на добавление в существующий файл проходят.
```

**Когда использовать:**
- Нужен специфический стиль
- Консистентность в проекте
- Нестандартные требования

---

## 📊 Сравнение

| Аспект | Zero-shot | Few-shot |
|--------|-----------|----------|
| Скорость написания | ⚡ Быстро | 🐢 Медленно |
| Контроль стиля | ❌ Нет | ✅ Полный |
| Консистентность | ⚠️ Средняя | ✅ Высокая |
| Токены (стоимость) | 🟢 Меньше | 🟡 Больше — примеры едут в каждом промпте |

💡 Про стоимость: few-shot примеры — это контекст, который платится токенами на каждом запросе. Дешевле один раз вынести стиль в `AGENTS.md` (Неделя 3) — он будет подключаться автоматически, без копипасты в каждый промпт.

---

## 💡 Структурированный вывод

Для ревью и автоматизации требуй машиночитаемый формат — не прозу:

```markdown
Проверь модуль src/api/orders.py и верни ответ строго в JSON:

{
  "issues": [
    {"file": "...", "line": 0, "severity": "high|medium|low", "problem": "...", "fix": "..."}
  ],
  "summary": "краткое резюме"
}

Без markdown, без комментариев вокруг JSON.
```

Агент умеет отдавать JSON — такой ответ можно скармливать скрипту, чек-листу ревью или следующей итерации делегирования.

---

## ✅ Верификация

Zero-shot и few-shot проверяются одинаково: по критериям приёмки, не «по ощущению стиля».

```bash
# Few-shot просил стиль с logging? Проверь:
grep -n "logging" src/new_module.py
```

## 🎯 Миссия

Реши одну задачу из твоего проекта дважды: zero-shot и few-shot, и сравни результаты.

**Формат артефакта:** два промпта + два диффа + 3-5 строк сравнения (стиль/тесты/число итераций до «готово»).

**Проверка:** оба результата проходят критерии приёмки; few-shot версия не потребовала итераций «сделай в нашем стиле».
