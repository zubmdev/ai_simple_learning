## 🧠 Главная идея недели

```text
MCP = стандартизированный протокол для:
- Resources (чтение данных)
- Tools (выполнение действий — самое опасное)
- Prompts (готовые шаблоны)

+ Правило недели: каждый сервер получает минимум прав,
  каждый вызов инструмента — под твоим контролем.
```

MCP стандартизирует связь LLM с внешними системами, как HTTP стандартизировал веб. Но в отличие от браузера, где ты просто читаешь страницу, MCP-сервер выполняет действия от твоего имени — с правами твоего пользователя.
