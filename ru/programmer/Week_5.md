## 🧠 Главная идея недели

```
MCP = Универсальный протокол для:
- Resources (доступ к данным)
- Tools (выполнение действий)
- Prompts (шаблоны промптов)
```

MCP стандартизирует взаимодействие между LLM и внешними системами, как HTTP стандартизировал веб.
