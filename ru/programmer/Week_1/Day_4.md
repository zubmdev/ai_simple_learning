## 🔬 Анатомия промпта

### Компоненты

```markdown
## Роль
Ты — Senior Python разработчик, специализируешься на чистом коде.

## Задача
Напиши функцию для валидации email.

## Контекст
- Это для API регистрации
- Нужно отсеять невалидные email
- Используй только стандартную библиотеку

## Требования
1. Type hints
2. Docstring (Google format)
3. Handle edge cases
4. Return bool

## Ограничения
- Python 3.10+
- Без внешних зависимостей
- Без regex (если возможно)
```

### Минимальный промпт

```
Напиши Python функцию validate_email(email: str) -> bool
с валидацией формата и docstring.
```

---

## 🔄 Итеративный подход

### Паттерн: Базовая версия → Улучшения

```
Итерация 1:
"Создай REST API для блога на FastAPI с CRUD"

Итерация 2:
"Добавь валидацию Pydantic для всех endpoints"

Итерация 3:
"Добавь обработку ошибок и логирование"

Итерация 4:
"Напиши unit тесты с pytest"
```

### Почему это работает

| Подход | Результат |
|--------|-----------|
| Один большой промпт | AI может потерять контекст |
| Итеративный | Каждый шаг проверяется, меньше ошибок |

## 🧠 Продвинутые техники

### Chain of Thought (CoT)

```
Проанализируй задачу step-by-step:
1. Какие паттерны применимы?
2. Какие edge cases нужно учесть?
3. Какую архитектуру выбрать?

Потом напиши код.
```

### Few-shot (примеры)

```
Напиши функцию в таком стиле:

def get_user_by_id(user_id: int) -> User | None:
    """Получает пользователя по ID."""
    return db.query(User).filter_by(id=user_id).first()

Теперь напиши функцию get_user_by_email(email: str) -> User | None
```

### Code Review через AI

```
Проверь этот код на:
- Security vulnerabilities
- Performance issues
- Code smells
- Best practices violations

[Вставь код]
```

## 💡 Best Practices

### ✅ DO

```
✅ "Напиши функцию X с type hints и docstring"
✅ "Обработай edge cases: пустой ввод, None, неверный формат"
✅ "Используй Python 3.10+ match/case вместо if/elif"
```

### ❌ DON'T

```
❌ "Сделай что-нибудь с базой данных"
❌ "Напиши код" (слишком общее)
❌ "Исправь это" (без контекста ошибки)
```

## 🐛 Дебаггинг через AI

### Структура промпта

```markdown
**Ошибка:** [вставь traceback]

**Код:**
[вставь код]

**Что пробовал:**
1. [попытка 1]
2. [попытка 2]

**Вопрос:** Почему возникает ошибка и как исправить?
```

### Пример

```
Получаю ошибку: TypeError: 'NoneType' object is not subscriptable

Код:
def get_user_name(user_id):
    user = db.get(user_id)
    return user['name']

Помоги понять причину и исправить.
```
