## 🎯 Быстрый выбор

| Твой случай | Вариант | Модель | Действие |
|-------------|---------|--------|----------|
| CPU + бесплатный API (Tier 1) | **Groq API** (облако) | `openai/gpt-oss-20b` | Регистрация на console.groq.com |
| CPU + бесплатный API, альтернативы | Gemini AI Studio или OpenRouter (free-модели) | см. ADR-стек | Регистрация на aistudio.google.com / openrouter.ai |
| 4GB GPU + Ollama (Tier 2) | **Ollama** (локально) | `qwen3.5:2b` (запасной: `qwen3:4b`) | `ollama pull qwen3.5:2b` |
| 16GB GPU + Ollama (Tier 3) | **Ollama** (локально) | `gpt-oss:20b` | `ollama pull gpt-oss:20b` |

_Проверено: 2026-10-24_

💡 `qwen3-coder:30b` для Tier 3 — только с выгрузкой части слоёв на CPU (CPU offload). Модели крупнее 16GB (например, ~24GB-класс) в этот уровень не помещаются.

## 🟢 Вариант 1: Groq API (Cloud, Tier 1)

### Почему Groq?

- 🆓 Бесплатный tier: ~1000 запросов/день, ~30 запросов/мин, лимит 8K токенов на запрос (по состоянию на 2026-10-24)
- ⚡ Сотни токенов/сек на `openai/gpt-oss-20b`
- 🔧 OpenAI-совместимый API

### Настройка в Cline

```bash
# 1. Получи API key: https://console.groq.com/keys
# 2. Ключ храни только в настройках Cline или в .env —
#    не вставляй его в код, промпты и скриншоты
```

1. Открой панель Cline → иконка настроек (шестерёнка)
2. **API Provider:** `Groq`
3. **Groq API Key:** вставь ключ
4. **Model ID:** `openai/gpt-oss-20b`
5. Сохрани настройки (Done)

Для OpenCode: `opencode auth login` → выбери провайдера → вставь тот же ключ.

💡 Альтернативы Tier 1: **Gemini AI Studio** (бесплатный ключ на aistudio.google.com) и **OpenRouter** (free-модели, лимит ~50 запросов/день ниже 10 кредитов). В настройках приватности OpenRouter отключи обучение на бесплатных моделях.

## 🟡 Вариант 2: Ollama (Local, Tier 2–3)

### Установка Ollama

```bash
# macOS/Linux
curl -fsSL https://ollama.com/install.sh | sh

# Windows: скачай с https://ollama.com/download
# Или через winget
winget install Ollama.Ollama
```

### Модель по уровню железа

| Уровень | Команда | Качество |
|---------|---------|----------|
| Tier 2 (4GB GPU) | `ollama pull qwen3.5:2b` | ⭐⭐⭐⭐ |
| Tier 2 запасной (4GB GPU) | `ollama pull qwen3:4b` | ⭐⭐⭐⭐ |
| Tier 3 (16GB GPU) | `ollama pull gpt-oss:20b` | ⭐⭐⭐⭐⭐ |

_Проверено: 2026-10-24_

### Проверка GPU

```bash
ollama run qwen3.5:2b "скажи ok" --verbose

# В выводе "PROCESSOR" должно быть 100% GPU
```

### Настройка Cline для Ollama

1. Панель Cline → настройки (шестерёнка)
2. **API Provider:** `Ollama`
3. **Base URL:** `http://localhost:11434`
4. **Model ID:** `gpt-oss:20b` (или `qwen3.5:2b` для Tier 2)
5. Сохрани настройки (Done)

## 🔧 Проверка

```bash
# Для Groq
curl -H "Authorization: Bearer $GROQ_API_KEY" \
  https://api.groq.com/openai/v1/models

# Для Ollama
ollama list
```

В Cline отправь агенту: «Ответь одним словом: готов». Ответ приходит — модель подключена.

---

## 🎯 Миссия

Подключи одну модель к Cline и получи первый ответ агента.

**Формат артефакта:** ответ агента на промпт «Ответь одним словом: готов» + одна строка в заметке: какая модель выбрана (провайдер и ID модели).

**Проверка:** в настройках Cline указан провайдер и ID модели из таблицы уровней выше; агент отвечает; для Ollama `ollama list` показывает скачанную модель.
