# День 1: AGENTS.md — Правила Проекта 📜

**Трек:** 👨‍💻 Программист | **Время:** 15 минут

---

## 🎯 Миссия

Создать в проекте `AGENTS.md` с пятью правилами и убедиться, что агент
применяет их без напоминаний. Артефакт: файл в корне проекта + правка от
агента, в которой стиль и формат ответа совпадают с правилами.

---

## 💡 Правила вместо повторений

**Правила** — инструкции, которые агент получает в каждой задаче
автоматически, без твоих повторов.

```text
Без правил:
Ты: "Напиши функцию"
ИИ: *пишет без type hints, без docstring*

С правилами:
Ты: "Напиши функцию"
ИИ: *пишет с type hints и docstring — так сказано в AGENTS.md*
```

**Аналогия:** rulebook команды на вики, а не напоминания в личке каждому
новичку.

> 💡 **Миграция со старого курса:** раньше правила хранились в
> `.continuerules` или в `config.json` (Continue). Теперь стандарт —
> `AGENTS.md` в корне репозитория: его читают OpenCode и другие агенты
> автоматически. В Cline правила можно держать в `.clinerules/`; мы будем
> вести один `AGENTS.md` как единый источник для обоих инструментов.

## 🛠️ Практика

**1. Создай проект:**

```bash
mkdir blog-api && cd blog-api
git init 2>/dev/null; mkdir app
```

**2. Создай AGENTS.md** (в OpenCode: команда `/init` сгенерирует черновик —
вычитай и сократи; в Cline — просто создай файл руками):

```markdown
# AGENTS.md

## Проект
FastAPI-блог: посты, комментарии. Структура: app/api, app/models, app/services.

## Стек
Python 3.12, FastAPI, Pydantic v2, pytest. Миграции — не используем.

## Стиль кода
- Type hints во всех функциях
- async/await для I/O
- Docstring — одна строка, по делу
- Без очевидных комментариев

## Ответы агента
- Кратко: код первым, максимум 3 предложения пояснений
- Язык ответов: русский

## Безопасность
- Секреты только через .env, в коде — никакого хардкода ключей
```

**3. Проверь, что правила работают:**

```text
Напиши в app/services посты: функцию list_posts(offset, limit)
со срезом списка. Без фреймворка, просто функция.
```

Проверь результат по правилам: type hints есть? Пояснение короткое и на
русском? Docstring одной строкой?

**4. Почини дырку в правилах.** Найди то, что агент сделал не так, — и
добавь правило, которое это запрещает. Например:

```markdown
- По умолчанию не создавать новые файлы — менять существующие
```

Перезапусти задачу в новой сессии и сравни.

---

## 🚨 Правила пишутся коротко

```text
❌ 50+ правил, трактаты о философии проекта
✅ 5–10 конкретных проверяемых правил

❌ "Пиши хороший код"
✅ "Type hints, async/await, docstring одной строкой"
```

Противоречивые правила агент выполняет непредсказуемо — вычитай файл после
каждого большого изменения проекта.

---

## 📊 Правило vs Промпт

| Аспект | Правило (AGENTS.md) | Промпт (чат) |
|--------|---------------------|--------------|
| Применение | Каждая задача | Один раз |
| Живёт | В репозитории, видит команда | В сессии |
| Что класть | Стабильное: стиль, стек, границы | Текущее: конкретная задача |
