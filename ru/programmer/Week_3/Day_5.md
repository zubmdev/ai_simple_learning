## 🛠️ Практика

### Шаг 1: Создай проект

```bash
mkdir todo-cli && cd todo-cli
```

```python
# todo.py
import json
import os

TODO_FILE = "todos.json"

def load_todos():
    if os.path.exists(TODO_FILE):
        with open(TODO_FILE, 'r') as f:
            return json.load(f)
    return []

def save_todos(todos):
    with open(TODO_FILE, 'w') as f:
        json.dump(todos, f, indent=2)

def add_todo(text):
    todos = load_todos()
    todos.append({"text": text, "done": False})
    save_todos(todos)
    print(f"Added: {text}")

def list_todos():
    todos = load_todos()
    for i, todo in enumerate(todos, 1):
        status = "✓" if todo["done"] else " "
        print(f"{i}. [{status}] {todo['text']}")

def main():
    print("Todo CLI")
    while True:
        cmd = input("> ").strip().split(maxsplit=1)
        if not cmd:
            continue
        if cmd[0] == "add" and len(cmd) > 1:
            add_todo(cmd[1])
        elif cmd[0] == "list":
            list_todos()
        elif cmd[0] == "exit":
            break

if __name__ == "__main__":
    main()
```

Проверка базы: запусти `python todo.py`, добавь задачу, выведи список.

### Шаг 6: Финальная проверка


Финальный артефакт: вывод трёх сценариев в терминале. Он и есть
верификация — не доверяй словам агента, смотрите вывод вместе.

## 📊 Ручной режим против агента

| Шаг | Вручную | С агентом |
|-----|---------|-----------|
| Понять структуру | 20 мин | 2 мин (карта) |
| Цвета | 30 мин | 3 мин |
| Категории | 40 мин | 5 мин |
| Приоритеты | 30 мин | 5 мин |
| Проверка сценариев | 20 мин | 5 мин |

Экономия реальна, но только если на каждом шаге был контекст и прогон.
Агент без проверки «сэкономленное» время возвращает багами.
