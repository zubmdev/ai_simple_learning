## 🎯 Миссия

Починить ошибку максимум за три итерации «запуск → traceback → правка».
Артефакт: команда завершается успешно + тест, который воспроизводил
ошибку, теперь зелёный.

## 💡 Traceback — самый плотный контекст

Traceback содержит файл, строку и причину. Это в разы полезнее любых
описаний словами. В 2026 агент не пассивен: он сам запускает команды и
читает вывод.

```text
Кто поставляет вывод терминала:
1. Агент сам: Cline выполняет команды (с твоего одобрения),
   OpenCode исполняет bash в цикле — вывод попадает в контекст
2. Ты явно: вставил traceback в промпт или упомянул @terminal (Cline)
3. Инструменты: @problems (Cline) подтягивает ошибки из панели Problems
```

**Аналогия:** ты не пересказываешь врачу свои анализы по памяти — ты
приносишь распечатку. Терминальный вывод и есть распечатка.

## 🧠 Структура debug-запроса

```text
1. Симптом: что запускал и что увидел
2. Ожидание: как должно работать
3. Файл: путь к месту, которое подозреваешь
4. Шаги: сначала воспроизведи, потом чини, потом прогони снова
```

Минимальный запрос:

```text
Команда python app.py падает. Воспроизведи ошибку,
найди root cause, исправь и запусти ещё раз.
```

Продвинутый запрос:

```text
@app.py @utils.py

Команда python app.py падает с TypeError.
1. Воспроизведи ошибку и покажи traceback.
2. Root cause: где и почему ломается?
3. Исправь + добавь проверку входных данных.
4. Напиши pytest-тест, который ловит эту ошибку.
5. Прогони тест и покажи результат.
```

## 🛠️ Практика

### Кейс 1: ZeroDivisionError

```python
# error1.py
def divide(a, b):
    return a / b

result = divide(10, 0)
print(result)
```

```text
Запусти error1.py, объясни ошибку и исправь
через defensive programming: divide(a, b, default=0.0).
Добавь тест на деление на ноль.
```

### Кейс 2: ImportError

```python
# error2.py
from nonexistent_module import some_function

some_function()
```

```text
Запусти error2.py. Какого модуля не хватает?
Устанавливать нечего — замени импорт на заглушку
с понятным сообщением об ошибке.
```

### Кейс 3: TypeError на None

```python
# error3.py
def process(data: dict):
    return data["key"]

process(None)
```

```text
@app.py не нужен, работаем с error3.py.
1. Воспроизведи ошибку.
2. Исправь: валидация входа + понятное сообщение.
3. Тест с параметрами: валидный dict, None, dict без ключа.
```

**Для каждого кейса проверь:** агент запускал код сам и его финальный
запуск зелёный; тест на месте и падает без фикса (проверь через
`git stash`, если работаешь с git).

## 💡 Best Practices

```text
✅ Проси сначала воспроизвести — не чинить вслепую
✅ Проси тест, который ловит ошибку
✅ Проси объяснить "почему", а не только "как"
❌ Вставлять весь лог на 500 строк — режь до traceback
```
