# День 1: Бюджет Контекста 🪙

**Трек:** 👨‍💻 Программист | **Время:** 20 минут

---

## 🎯 Миссия

Дать агенту задачу «добавь поле `email` в модель пользователя» так, чтобы он
прочитал не больше трёх файлов. Артефакт: список файлов, которые агент
реально открыл (из истории его действий) + внесённая правка.

---

## 💡 Что такое контекст

```text
Context = информация, которую ИИ "видит" прямо сейчас:
системный промпт + правила проекта + твоя задача +
прочитанные файлы + вывод команд + история диалога
Quality of Context → Quality of Response
```

Одна сессия — один бюджет. Всё, что агент прочитал или вывел в терминал,
остаётся в контексте до конца сессии.

---

## 📊 Context Bloat

**Context Bloat** — перегрузка модели ненужной информацией.

| Прочитано файлов | Время ответа | Качество |
|------------------|--------------|----------|
| 1–3 | ⚡ Быстро | ⭐⭐⭐⭐⭐ |
| 5–10 | 🚶 Нормально | ⭐⭐⭐⭐ |
| 20+ | 🐢 Медленно | ⭐⭐⭐ |
| 100+ | 💀 Очень медленно | ⭐⭐ |

Почему качество падает:

```text
Больше файлов → агент теряет фокус
Больше токенов → выше шанс галлюцинаций
Длинная история → ранние правила "забываются"
```

### 🚨 Кто съедает бюджет в Cline и OpenCode

```text
1. Ты: длинный промпт со вставленным кодом
2. Агент: прочитал файлы "на всякий случай"
3. Агент: вывел в терминал огромный лог или вывод тестов
4. Сессия: тянешь одну сессию через пять разных задач
```

Контроль: у Cline есть индикатор заполнения контекстного окна, у OpenCode —
команда `/compact` (сжать историю) и `/new` (начать с чистого листа).
Новая задача → новая сессия.

---

## 🔬 Правило 3 файлов

```text
1. Файл, который правишь → назови путь
2. Его прямые зависимости → назови или дай агенту найти
3. Конфигурация → только если меняешь настройки
Остальное НЕ подавай: агент найдёт сам, но токены спишутся с тебя.
```

Ключевой сдвиг по сравнению с чат-ботами: агенту не нужно вставлять код в
промпт. Он читает файлы сам. Твоя работа — назвать точки входа и потом
проверить в истории действий, что он прочитал именно их.

## 🛠️ Практика

**1. Создай мини-проект:**

```bash
mkdir ctx-budget && cd ctx-budget
```

```python
# models.py
class User:
    def __init__(self, name: str):
        self.name = name
```

```python
# config.py
DEBUG = False
```

```python
# main.py
from models import User

user = User("Ann")
print(user.name)
```

**2. Задача агенту (Cline или OpenCode):**

```text
Добавь в класс User поле email (обязательное).
Файлы: models.py, main.py. config.py не трогай.
После правки запусти main.py и покажи вывод.
```

**3. Проверь:**

- [ ] В истории действий агент открыл ровно `models.py` и `main.py`
- [ ] `config.py` не прочитан
- [ ] Скрипт запускается

**4. Контрольный замер:** задай тот же вопрос вторым сообщением в длинной
сессии и в новой сессии. Сравни скорость и качество ответа.
