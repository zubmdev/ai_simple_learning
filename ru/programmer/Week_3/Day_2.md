# День 2: Явный Контекст — Выбираем Файлы 📎

**Трек:** 👨‍💻 Программист | **Время:** 25 минут

---

## 🎯 Миссия

Выполнить одну и ту же задачу двумя способами — «приложил файлы сам» и
«агент ищет сам» — и сравнить количество действий агента. Артефакт: два
выполненных задания + записанное число шагов (чтений файлов) в каждом.

---

## 💡 Два способа дать контекст

```text
1. Явный: ты прикладываешь файлы или называешь пути
   → быстро, дёшево, но нужно знать, что нужно

2. Самостоятельный: агент сам ищет по репозиторию (grep, чтение)
   → не нужно знать структуру, но каждая попытка — токены и время
```

**Аналогия:** новый джун в проекте. Если сказать «логика скидок в
`src/pricing/discount.py`» — он откроет один файл. Если сказать «найди, где
считаются скидки» — он будет ходить по папкам. Иногда это оправдано, чаще —
нет.

**Правило:** знаешь, где код — подавай явно. Не знаешь — сначала
ориентационный проход (завтрашний день), потом явные файлы.

---

## 🛠️ Как подать файлы явно

### Cline

Перетащи файл в чат или упомяни его через `@` — по пути:

```text
@src/pricing/discount.py

Перепиши calculate_discount() с учётом купонов.
Купон хранится в Cart.coupon_code.
```

Полезные упоминания в Cline:

| Упоминание | Что даёт |
|------------|----------|
| `@путь/к/файлу.py` | Конкретный файл |
| `@problems` | Ошибки из панели Problems |
| `@terminal` | Последний вывод терминала |

### OpenCode

Набери `@` и Tab — дополнение путей по репозиторию:

```text
@src/pricing/discount.py @src/models/cart.py

Перепиши calculate_discount() с учётом купонов.
```

## 📁 Файл, папка или путь словами?

| Ситуация | Что подать |
|----------|------------|
| Правишь конкретную функцию | 1–3 файла явно |
| Просишь понять модуль целиком | Папку (до ~10 файлов) или путь словами |
| Не знаешь, где код | Не подавай всё — пусть агент ищет целенаправленно |
| Ошибка в терминале | Лог/traceback + файл, на который он указывает |

```text
❌ 10+ файлов "на всякий случай"
✅ 2–3 файла + чёткая задача
```

## 🛠️ Практика

**1. Создай файлы:**

```bash
mkdir ctx-files && cd ctx-files
```

```python
# test.py
def greet(name: str) -> str:
    return f"Hello, {name}!"
```

```python
# utils.py
def shout(text: str) -> str:
    return text.upper() + "!"
```

**2. Способ А — явно (Cline: `@test.py @utils.py`, OpenCode: `@` + Tab):**

```text
@test.py @utils.py

Добавь в test.py функцию loud_greet(name), которая
использует shout из utils.py. Запусти проверку.
```

**3. Способ Б — без явных файлов:**

```text
Добавь в test.py функцию loud_greet(name), которая
использует shout из utils.py. Найди нужные файлы сам.
```

**4. Сравни:** посчитай в истории действий, сколько файлов агент открыл
в каждом способе. Запиши оба числа — это твоя точка отсчёта по экономии
бюджета.
