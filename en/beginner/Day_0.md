## 📖 How to Use This Course

This course is written in **Markdown** format (`.md` files). Here's how to read it.

### Recommended: VS Code

VS Code is the editor we'll use throughout the course. Perfect for Markdown!

**Steps:**
1. Install VS Code → [code.visualstudio.com](https://code.visualstudio.com)
2. Open file: `File` → `Open File...` → select `.md` file
3. Preview Markdown: `Ctrl + Shift + V` (Windows/Linux) or `Cmd + Shift + V` (macOS)

### Recommended Plugin

**Markdown Preview Enhanced:**
1. Open Extensions: `Ctrl + Shift + X`
2. Search: `Markdown Preview Enhanced`
3. Install

**Adds:**
- 📑 Table of contents
- 🎨 Syntax highlighting
- 📄 Export to PDF

### Alternative Editors

| Editor | Pros | Cons |
|--------|------|------|
| **Obsidian** | Beautiful, notes | Separate install |
| **Typora** | WYSIWYG | Paid ($15) |
| **Browser** | No install | No editing |

> 💡 **Tip:** Use VS Code — you'll need it for coding anyway!

## 🆘 Where to Get Help

### If you're stuck

1. **Ask AI in Continue:** "I'm stuck on [step]. Explain simply what to do."

2. **Official documentation:**
   - VS Code: https://code.visualstudio.com/docs
   - Continue.dev: https://continue.dev/docs
   - Ollama: https://ollama.ai/docs

3. **Communities:**
   - Continue Discord: https://discord.gg/continue
   - Ollama Discord: https://discord.gg/ollama

### If you get an error

1. Copy the error text
2. Paste in Continue with: "Here's the error: [error]. How to fix?"
3. AI will explain and give a solution

### If nothing makes sense

1. Ask AI: "Explain this like I'm 5 years old."
2. Or: "Explain simply, without technical terms."
3. Or: "Give a real-life example so I understand."
