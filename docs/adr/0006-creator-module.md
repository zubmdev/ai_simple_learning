# Creator module, not a third track

**Status:** accepted
**Date:** 2026-10-24

Add a **Creator module** inside the Beginner track plus a standalone free lead magnet. Do not launch a third 8-week track until demand is validated.

## Scope

The module teaches one pipeline: idea -> script -> storyboard -> image/video generation -> voice -> edit -> publish. It is FOSS-first (for example ComfyUI, Stable Diffusion/Flux, FFmpeg, Whisper, Piper, Kdenlive); proprietary tools are optional and clearly labeled. It includes consent, copyright, disclosure, and no-impersonation rules.

## Why

A full Creator track triples the content and support surface before the core coding offer is validated. One applied module tests demand, gives beginners a tangible project, and can become a lead magnet without delaying the launch.

## Consequences

- The module is an alternate Week 6 project, not a replacement for the coding path.
- Image/video generation needs a separate hardware note; 4GB GPUs may require cloud/free APIs.
- Promote the module to a full track only after 20+ paid learners request it.
- Do not mix creator tools into the core coding setup lessons.
